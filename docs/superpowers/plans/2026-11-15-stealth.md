# Stealth: the Cloak Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A cloak on foot that hides you from guards, street foes, cameras and walkers until your first hit, which lands as an ambush; drawn from FOCUS (the Stealth skill's Cloak) or from a field scrambler's own cell; Vanish breaks a fight and cloaks you to get away; the veil drifts the map in pink and cyan while it holds (#36).

**Architecture:**
- The game crate learns three things: a skill can grant abilities (`Skill.grants`, `Source::Skill`), an item can hold a cell and grant while carried (`Item.cell`, `ItemCopy.charge`), and two new active kinds (`Active::Cloak`, `Active::Vanish`). Content adds the Cloak, Scramble and Vanish abilities, the field scrambler and its recipe, and rewires the STREET talents.
- A new `cloak` module in strata-zero holds the saved state (`AppState.cloak`), switching on and off, the drain on map frames, the scrambler's cell, Vanish and the veil. Everything that looks at you on foot asks `cloak::hidden`; `combat::volley` takes the ambush.
- The veil is a cell post-pass beside `daze::draw`: a port of the mock's `look()` to frame ticks, applied to a grid of grounds (empty floor takes copies, walls, furniture and foes throw them), with foes and your `@` put back on their true cells.

**Tech Stack:** Rust workspace (`crates/game`, `crates/strata-zero`); serde (`#[serde(default)]`) for saves and content (RON); ratatui buffers; `citygen::rng::hash64` for the veil's randomness.

**Spec:** `docs/superpowers/specs/2026-11-15-stealth-design.md`, with its mock `docs/superpowers/specs/2026-11-15-stealth-mock.html` (its `<script>` is the agreed animation). Every "(call)" in the spec is decided; this plan settles what it leaves to the builder.

## Rulings

Where the spec leaves a choice to the builder, or the code forces one, this plan decides:

1. **Ruling (content):** three abilities, each `cooldown` in frame ticks: `cloak` "Cloak" `Active(Cloak)` cooldown 0 (granted by the Stealth skill); `scramble` "Scramble" `Active(Cloak)` cooldown 0 (granted by the scrambler); `vanish` "Vanish" `Active(Vanish)` cooldown 3600 (granted by Shadow step rank 1). None plays an `fx`: the veil is their look. The item `field_scrambler` "Field scrambler", `kind: Component`, weight 0.4, value 900, `cell: true`, `grants: ["scramble"]`, no slot. Its recipe `field_scrambler_build` "Field scrambler", skill `electronics`, inputs `("dead_phone", 1), ("copper_coil", 3), ("scrap_servo", 1)`, output `("field_scrambler", 1)`, steps `["gut the phone", "wind the coil"]`. Shadow step's effects become `[[Grant("vanish")], [Sharpen(ability: "vanish", cooldown: -900)]]`; Ghost and Blind spot keep their flags, which `game::flag_words` now names: `ghost` → `cameras that see you warm the trace at half rate`, `blind_spot` → `standing still, a cloak drains at half rate`. The Vanish *skill* is unchanged. The Stealth skill gains `grants: ["cloak"]`.
2. **Ruling (grants):** `Skill.grants: Vec<AbilityId>` and `Item.cell: bool` are `#[serde(default)]`. `Character::abilities` gathers, first source winning: innate; categories (content order); owned skills (content order of `c.skills`) as `Source::Skill(id)`; worn items (slot order); chrome; carried items with `cell` (pack order) as `Source::Item(id)`; talents. `Source::Skill(SkillId)` is the enum's last variant. Content validation: an item's grants are allowed with a slot, an implant, a bot, or `cell`; an item with `cell` grants exactly one ability and it is `Active(Cloak)` (`ContentError::ItemInvalid`-style error, the existing error type for items); every skill grant names a known ability. `Item::per_copy` is also true for `cell`.
3. **Ruling (the charge):** `game::FULL_CELL: u32 = 10_800` (divisible by every rate below). `ItemCopy` gains `#[serde(default)] pub charge: Option<Charge>` with `#[derive(Clone, Copy, Debug, Default, PartialEq, Eq, Serialize, Deserialize)] pub struct Charge { pub left: u32, pub burned: bool }`. `Character::new_copy` sets `Some(Charge { left: FULL_CELL, burned: false })` for an item with `cell`, `None` otherwise. `ItemCopy::cell(&self) -> Charge` reads `None` as full. Every `ItemCopy { .. }` literal (11 of them) gains `charge: None`.
4. **Ruling (the state):** `AppState.cloak: Option<cloak::Cloak>` is saved (`Snapshot.cloak` is `#[serde(default)]`); `AppState.veil: cloak::VeilState` is UI (bound `_`, reset on restore):
   ```rust
   #[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
   pub struct Cloak {
       pub pool: Pool,
       pub since: u64,                     // the frame tick it went on
       #[serde(default)] pub drained_to: u64, // the frame tick last drained
       #[serde(default)] pub at: Pos,       // your tile at the last frame
       #[serde(default)] pub moved: u64,    // the frame tick you last changed tile
       #[serde(default)] pub waiting: bool, // on turns by hand from it (Ruling 8)
   }
   #[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
   pub enum Pool { Focus { start: u32, owed: u32 }, Cell(game::CopyId), Free { until: u64 } }
   #[derive(Clone, Debug, Default, PartialEq)]
   pub struct VeilState { pub fade: Option<Fade>, pub off: bool } // off: tests and shots keep the map plain
   #[derive(Clone, Copy, Debug, PartialEq)]
   pub struct Fade { pub phase: Phase, pub since: u64, pub hot: f32 }
   #[derive(Clone, Copy, Debug, PartialEq, Eq)]
   pub enum Phase { Holding, GoingIn, BurningOut, SwitchingOff }
   ```
   A reopened run has `veil.fade == None`, so a cloak comes back holding, with no going in.
5. **Ruling (switching):** `actions::perform(Action::Fire(id))` on an `Active(Cloak)` ability returns `cloak::toggle(st, &id)` before any action point or `game::apply` (no cooldown is stamped); on `Active(Vanish)` it returns `Err("use it from the map")` while engaged and `Err("only in a fight")` in calm. `toggle`: with any cloak on, either cloak key switches it off (`End::Off`) and returns `scrambler off · {pct}% left` (cell) or `cloak off` (FOCUS, free). Else it refuses, in this order: no body → `no body in the city`; `actions::jacked_in` → `not while jacked in`; your place is a construct or the Net stratum → `not on the Net`; `st.net.engaged.is_some()` → `not in a fight`; the pool empty → `no FOCUS left` (FOCUS 0) or `the cell is empty` (no carried scrambler copy with `left > 0`). The pool: the ability's source (`Character::abilities`) is `Source::Item(id)` of an item with `cell` → `Pool::Cell` of the carried copy of that item with the most `left` (ties: pack order); any other source → `Pool::Focus { start: focus, owed: 0 }`. On: `st.cloak = Some(..)` with `since = drained_to = moved = st.tick`, `at` your tile, a `Fade { phase: GoingIn, since: st.tick, hot }`, and the line `SCRAMBLED` (cell) or `CLOAKED` (FOCUS).
6. **Ruling (the drain):** `cloak::frame(st)` runs once per `MapScreen::update` in Walk mode, before the calm look (`foes::look_all`). It first ends a cloak (`End::Off`) when there's no body, you're jacked in, your place is a construct or the Net, or its `Pool::Cell` copy is no longer in the pack. Then, if `st.tick > drained_to`, it drains **one frame** (time off the map, in the deck or a menu, costs nothing) and sets `drained_to = st.tick`. Standing still: your tile unchanged for `STILL_TICKS = 15` frame ticks (`at`/`moved` updated each frame). Units a frame: `DRAIN_MOVING = 2`, or `DRAIN_STILL = 1` standing still with the `blind_spot` flag. FOCUS: `owed += units`; at `FOCUS_UNITS = 60` owed, one FOCUS goes (1 a second); FOCUS at 0 burns it out. Cell: `left -= units × CELL_RATE`, `CELL_RATE = 9` (600 frames, 20 s), `CELL_RATE_SKILLED = 6` with the Stealth skill (900 frames, 30 s); `left` at 0 sets `burned` and burns it out. Free: `st.tick >= until` ends it (`End::Off`).
7. **Ruling (ends):** `cloak::end(st, End) -> bool` takes the cloak and starts its fade from the heat it had: `End::Off`, `End::Ambush` and `End::Fight` → `SwitchingOff`; `End::Burnout` → `BurningOut` (`hot` 1.0) and the warning `the scrambler burns out · you're in the open` (cell) or `the cloak burns out · you're in the open` (FOCUS). Called by: `toggle`; `frame` (Ruling 6); `combat::volley` (`Ambush`); `blast::throw` after its refusals (`Off`, no bonus); `net::engage` (`Fight`, unless `waiting`); `net::after_jack_in` (`Off`); Vanish's free cloak running out (`Off`). Moving, doors, stairs, lifts and crossing into a building end nothing.
8. **Ruling (the first hit needs turns):** shooting, striking and throwing happen on the act half of a turn, so a fight you start by hand from the cloak is not "a fight starting": `e` while cloaked (the `explore.rs` arm that engages when `foes::in_memory` isn't empty) calls `cloak::engage_by_hand(st, place)`, which sets `waiting = true` and calls `net::engage(st, place, true)`; `engage` ends the cloak only when `!waiting`. While waiting the cloak hides you as ever (foes taking turns before yours don't see you and pass), and it ends with your attack (the ambush) or a throw; a Mark or a boost leave it on. `net::disengage` sets `waiting = false`. Switching it on stays refused on turns.
9. **Ruling (hidden):** `cloak::hidden(st) -> bool` is `st.cloak.is_some()` (a burnout's fade is not hidden: you're in the open from its start). While hidden: `foes::look` sees nothing (no hunt, no `spotted`, returns `foe.hunting()` unchanged); `foes::look_all` returns `false` (no fight starts from the cloak); `foes::step` never takes you as in reach (`in_reach` also needs `!hidden`), so a hunting foe walks to its last `seen` and loses you as on losing sight; `cameras::seeing` is empty; `exposure::of` lists no eyes and no cameras. `foes::sees` stays a test of a tile (a guard still finds your body by it); `guards::hear` is untouched, so the ambush shot is heard.
10. **Ruling (the ambush):** `combat::volley`, before its rounds, asks `cloak::ambush(st) -> bool`: hidden → `end(st, End::Ambush)`, `st.warn("AMBUSH")`, true. On an ambush every round hits without a roll and does `w.damage.saturating_mul(2)`; the foe still turns to hunting from where you stood. Both `combat::fire` and `combat::strike` go through it; a strike's chain hops don't (the cloak is gone by then).
11. **Ruling (Vanish):** `cloak::vanish(st, id) -> Result<(), String>` from `MapScreen::use_ability` (`act_list` lists `Active(Vanish)` off the Net). Refusals: not engaged → `only in a fight`; in a construct or on the Net → `not in here`; `casts::can_act(st, 0)`; then `casts::book(st, id)` stamps its cooldown. Then: `net::disengage`; every standing foe on your place turns `Idle`; every foe with a `post` whose building is the one you stand in (any floor), and every guard on your place, goes through `guards::hunt::lose_you` (made `pub(crate)`) and gets `spotted = false` (its `follow` is let go by `lose_you`); `radioed` and the alarm stand. Then `st.cloak = Some(Cloak { pool: Pool::Free { until: st.tick + VANISH_TICKS }, .. })`, `VANISH_TICKS = 120`, a going-in fade at `VANISH_HEAT = 0.2`, and the line `vanish · they lose you`.
12. **Ruling (the cell's clock):** `clock::run` calls `cloak::recharge(st, world_ticks.unwrap_or(0))` after `guards::tick`: every carried copy with a charge, except the one a cloak runs on, gains `CELL_RECHARGE = 4` a clock tick (2700 ticks, 30 game minutes, empty to full), capped at `FULL_CELL`; `burned` clears once `left > FULL_CELL / 10`. (The spec's call 1 says the cell recharges in 2 game minutes; its rules and call 10 say 30, about a minute and a half on foot. This plan follows 30.) `rest::wake` after a sleep calls `cloak::fill_cells(st)`: every carried copy full, `burned` cleared.
13. **Ruling (heat):** `cloak::heat(st) -> Option<f32>`: Cell `1 - left / FULL_CELL`; Focus `(start - focus) / start` (0 when `start` is 0); Free `VANISH_HEAT`.
14. **Ruling (the veil's look):** `cloak::veil::look(phase: Phase, p: f32, hot: f32, roll: &dyn Fn(u64) -> f32) -> Look` is the mock's `look()` (`offStyle` "ease", the v6 switch-off), with `Look { heat: f32, split: i32, veil: f32, wave: bool, plain: bool }`, `rest(h) = 1 + round(2.4 h)`, `ease(t) = t²(3 − 2t)`, `lerp` clamped, the shiver from rolls 0 (chance `< min(1, h)` when `h > 0.35`), 1 (sign) and 2 (`h > 1.2` adds `roll(2) < 0.5 ? 0 : 1`), the plain frame from roll 3. `p` is the phase's progress 0..1: `GoingIn` over `START_TICKS = 33`, `BurningOut` over `BREAK_TICKS = 72`, `SwitchingOff` over `SNAP_TICKS = 15` frame ticks; `Holding` has `p = 1`. A plain frame forces `split 0, veil 0, wave false`. `roll(k)` is `hash64(hash64(tick / VEIL_STEP, k), seed) as f32 / u64::MAX as f32` with `VEIL_STEP = 3` (the mock steps every 90 ms; 3 frames is 100 ms) and `seed = hash64(you.x as u64, you.y as u64)`, so a shot at a fixed tick and tile is a fixed frame. Reduced motion is not ported (the terminal has no such setting).
15. **Ruling (the veil's cells):** `cloak::veil::draw(buf, map: Rect, look: &Look, tick: u64, seed: u64, ground: &dyn Fn(u16, u16) -> Ground, you: Option<(u16, u16)>, keep: &[(u16, u16)])`, `enum Ground { Empty, Solid, Off }`, over a clone of the buffer as daze does, touching only `map ∩ buf.area`:
    - Copies: each `Solid` cell (never `you`) throws its symbol `split` cells left in `PINK = MAGENTA (255,0,200)` and right in `CYAN (0,229,255)`; a cell both land on takes `NEAR_WHITE = (244,248,255)`; a copy lands only on an `Empty` cell, its fg mixed from the cell's bg (`PANEL_BG` when not Rgb) toward its colour by `min(1, 0.5 + 0.45 × heat)`.
    - With `veil > 0.5` every `Empty` cell left without a copy has its fg mixed toward CYAN by 0.28.
    - The wash: every map cell's bg mixed toward CYAN by `0.05 × veil`, and by `0.13 × veil` on rows where `(y − map.y) % 3 == 0` (the scanline).
    - The wave (when `wave`): `t = tick × 1000 / 30` ms; `band = min(H − 2, 1 + round(4 heat))`; `period = max(35, 150 − 100 heat)` ms; `head = floor(t / period) % (H + band + 4)`; a row `r = y − map.y` with `0 ≤ head − r < band` shifts `max(1, round((1 + 2 heat) × mid))` where `mid = 1 − |into − (band − 1)/2| / max(1, band/2)`, negated when `floor(t / 600)` is odd; the slip (roll 4 `< min(0.5, 0.12 heat²)`) adds 1 to every row. Your row never shifts; a row shifted in from outside the map is blank (`PANEL_BG`), as daze.
    - Last, every cell in `keep` and your `you` cell are copied back from the pre-veil buffer: a foe stays on its true cell, your `@` never moves. Copies may land on your row's empty floor, as in the mock; your `@` never takes or throws one.
    - A look that is `plain`, or has `split 0`, `veil 0` and no wave, returns before touching the buffer.
    - `cloak::veil::draw_map(buf, map: Rect, origin: Pos, st, mref: &MapRef)` is the explore glue: `ground` is `Solid` for a tile you see or remember that isn't walkable (`!mref.walkable`) or that holds a standing foe in your sight; `Empty` for a tile you see that is walkable whose drawn symbol is bare ground (`" "`, `"·"`, `"▫"`, `"."`); `Off` otherwise (people, items, you, your body, unseen tiles). `keep` is the screen cells of `foes::in_sight(st)`; `you` is your cell. It draws nothing when `st.veil.off`, or when neither a cloak nor a fade is on.
16. **Ruling (the veil's phase):** `cloak::veil::now(st) -> Option<(Phase, f32, f32)>` (phase, progress, hot): a live fade first (`GoingIn` while the cloak is on, else the fade's own phase) while its progress is below 1; else `Holding` at `heat(st)` while a cloak is on; else None. `cloak::frame` drops a fade whose progress reached 1 and sets `st.repaint = true` (as a glitch's end does).
17. **Ruling (the HUD):** the top-right line keeps the location and clock, and a tag sits right-aligned before the clock (`hud::location_tag_line(location, tag: Vec<Span<'static>>, clock, width)`; `location_line` calls it with none; the location is cut first). The tag, from `cloak::hud::tag(st)`, for the carried scrambler with the most charge: cloaked on its cell `◌ FIELD SCRAMBLER {pct:>3}%` cyan, the percentage pink (MAGENTA) when below a quarter; its burnout `◌ FIELD SCRAMBLER ▓▓ FAILING` blinking pink/cyan (`(st.tick / 4) % 2`); `burned` `◌ field scrambler {pct:>3}% · burned out` pink; else `◌ field scrambler {pct:>3}%` dim. A FOCUS cloak's burnout `◌ CLOAK ▓▓ FAILING`; no tag otherwise. While cloaked on a cell the XP row is `hud::cell_row(left, full, secs, colour, width)`: ` CELL  ` then `{secs}s left` then the bar, `secs = left.div_ceil(rate × 30)` at the moving rate. The footer (`hud::Footer`): `cloak: Option<CloakTag>` with `enum CloakTag { Scrambled, Cloaked, SignalLost { blink: bool } }` drawn where `HUNTED`/`ENGAGED` would be, taking their place; `ambush: bool` draws `AMBUSH · your first hit lands, ×2` (amber) at the right of row 2, after any prompt, while hidden with a foe in `foes::in_sight` that `combat::reach` allows at your weapon's range. The ability bar: `hud::SlotState::On` (drawn ` on`, cyan bold) for the cloak ability running (`Pool::Cell` → the `scramble` slot, `Pool::Focus` → `cloak`, `Pool::Free` → none).
18. **Ruling (tests):** `cloak::testutil` gives: `street() -> AppState` (`foes::testutil::lot(Pos::new(20, 8))`: you on the lot at (6,8), a goon out of its sight, `st.veil.off = true`); `stealthy(st)` (adds the Stealth skill); `armed(st)` (a Ratchet SMG copy worn in PRIMARY, `new_copy` then `wear`); `scrambler(st) -> CopyId` (`give_item` one, returns its copy); `set_charge(st, CopyId, Charge)` (writes the pack copy's charge); `frames(st, n)` (`n` times: `st.tick += 1; cloak::frame(st)`); `fire(st, id: &str) -> Result<String, String>` (`actions::perform(st, Action::Fire(AbilityId::new(id)))`). Floor tests use `sitenet::testutil::office_copy` and `guards::testutil`; veil tests use a synthetic grid as daze's.

## Review Focus

1. **A run saved while cloaked** reopens cloaked, on the same pool and drain, holding with no going in; one saved mid-burnout reopens uncloaked (Task 2, `a_cloaked_run_comes_back_cloaked`).
2. **The scrambler in use leaves the pack** (dropped, put on the ground, taken apart): the cloak switches off on the next frame, never draining a copy you don't hold (Task 3, `dropping_the_scrambler_in_use_switches_it_off`).
3. **Both sources at once:** pressing the other cloak key while one runs switches it off; there are never two, and the pool is the key's (Task 3, `the_other_key_switches_the_cloak_off`).
4. **Time off the map** (the deck open, a menu, a popup) costs the cloak nothing: the next frame drains one frame, whatever `st.tick` did meanwhile (Task 2, `time_off_the_map_costs_nothing`).
5. **A guard already hunting reaches your floor while you're cloaked:** no fight starts, it walks to its last `seen` and turns calm; nobody shoots you (Task 4, `a_hunting_guard_loses_you_while_cloaked`).
