# Turrets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mounted guns in a job's copy of a site (#97): a turret is a `Foe` that never
moves, sleeps until it or a camera sees you, turns one eighth at a time to follow you,
fires in the turns engine from a 30-round magazine, loses its plate before its HP, and can
be blinded from the Net by anyone or taken over with the Turncoat talent, when it fights on
your side.

**Architecture:** `Foe` gains `turret: Option<Turret>`; everything a foe gets (the turn
order, stuns, blasts, EMPs, marks, the footer, saving) comes free. A new `turrets` module
holds what only a turret does: its field (the camera's cone for all eight facings), its
clock (asleep, awake, sweeping), its turn (turn, fire, lose you), its Net verbs and its
looks. Where the engine branches on a foe (`foes::look`, `foes::turn_start`, `foes::step`,
`net::pools_for`, the seats, the chips) a turret takes its own arm. `combat` gains a plate
roll on gunfire and a foe-on-foe volley so a turret that's yours and the guards can shoot
each other.

**Tech Stack:** Rust 2024 workspace (`citygen`, `game`, `strata-zero`), ratatui cells,
crossterm keys, serde + RON for flavor, MessagePack (named) for saves.

**Spec:** `docs/superpowers/specs/2026-11-19-turrets-design.md` (mock and generator in
`docs/superpowers/specs/2026-11-19-turrets-mock/`, look A). Read `CLAUDE.md`,
`docs/saving.md` and `manual/README.md` before starting.

## Rulings (where the spec and the code disagreed, or the spec left it open)

1. **Turncoat's slot and The deep end.** The spec puts Turncoat in ICE's tier 4, column 3,
   under Black ICE, and has The deep end (tier 5, column 3) keep requiring Black ICE. The
   tree validator (`game::content`, "the trace from … runs through a talent") refuses a
   trace through a filled slot, and Black ICE → The deep end runs through exactly that
   slot. Turncoat keeps the spec's slot; **The deep end requires Turncoat**, so the line
   runs Black ICE → Turncoat → The deep end. A runner saved with The deep end and no
   Turncoat keeps The deep end (a prerequisite gates learning only).
2. **The turret's light rule.** The spec says it sees "near or lit, by the camera's rule".
   `cameras::sees` reads `TileMap::emitted`, which a floor's map doesn't give (always 0),
   so a floor camera only sees near. A turret on a floor sees a tile in its field with a
   clear line when it is within `cameras::DARK_REACH` or lit by the floor's own light
   (`map.light(p) >= foes::GUARD_LIT`, as `foes::sees` reads a floor): near or lit, by the
   floor's light.
3. **Its turn is one action.** A turret's whole turn (turn, then fire) happens in one
   `net::pace` step that returns `Step::Nothing`, so it reads as one log line
   (`turret turns SE › fires · …`) and the turn passes after it.
4. **A turret that's yours in the order** sits as `Actor::Foe(i)`, seated with the bots
   (scored like them, after the foes of the same score), and its chip, like the bots' and
   yours, is drawn in your colours: `turns::Chip` gains `ours: bool`.
5. **Remembered turrets** draw as containers and doors do on a remembered tile: their
   look dimmed to 0.45; unseen, not drawn.
6. **Shot at.** Gunfire (yours, an off hand's, foe on foe) rolls the plate; strikes and
   blasts don't ("hurt it as they hurt any foe"). A hostile turret shot at, asleep or
   awake, wakes hunting toward the shooter, as `volley` turns any foe; a blind one or one
   that's yours doesn't change.
7. **Extra saved state on `Turret`** beyond the spec's list, each `#[serde(default)]`:
   `told` (the tile it turns toward awake), `since` (the game minute it last woke or had
   you) and `next` (the clock tick it next turns awake). The spec's rules need them.
8. **`turret wakes`** is logged when an asleep turret wakes (to awake or straight to
   hunting) and it stands in your sight memory; an unseen one wakes silently.
9. **The gun:** item `turret_gun`, "Mounted gun", in no kit, recipe, shop or loot table.

**Files:**

**Interfaces:**
- Produces (`crate::cameras`): `pub fn in_cone_at(at: Pos, facing: Dir, p: Pos) -> bool`
  (today's `in_cone` sum: depth `ox*dx + oy*dy` in `1..=CONE_DEPTH`, side
  `|ox*dy - oy*dx| <= depth`); `pub fn cone_at(at: Pos, facing: Dir, blocks: impl Fn(Pos) -> bool) -> Vec<Pos>`
  (today's `cone_by`). `in_cone(cam, p)` and `cone_by` call them; camera behaviour is
  unchanged.
- Produces (`crate::turrets::field`):
  - `pub fn toward(from: Pos, to: Pos) -> Dir`
  - `pub fn aim(at: Pos, facing: Dir, target: Pos) -> Dir`
  - `pub fn turn_toward(facing: Dir, goal: Dir) -> Dir`
  - `pub fn in_field(at: Pos, facing: Dir, p: Pos) -> bool` (= `cameras::in_cone_at`)
  - `pub fn sees(map: &MapRef, at: Pos, facing: Dir, p: Pos) -> bool`: in its field, and
    `citygen::sight::sees(at, p, cameras::DARK_REACH, |q| map.tile(q).is_none_or(foes::blocks_sight), lit, |_| false)`
    where `lit(q)` is `citygen::lighting::tuning::LIT_SIGHT` when
    `map.light(q) >= foes::GUARD_LIT`, else 0 (Ruling 2).
  - `pub fn tiles(map: &MapRef, at: Pos, facing: Dir) -> Vec<Pos>`: `cameras::cone_at` with
    `map.tile(q).is_none_or(|t| t.blocks_sight())`.
  - `pub fn dir_word(d: Dir) -> &'static str`: `"N" "NE" "E" "SE" "S" "SW" "W" "NW"`.
  - `pub fn glyph(d: Dir) -> char`: `▲ ◥ ► ◢ ▼ ◣ ◄ ◤` for N, NE, E, SE, S, SW, W, NW.
  - The algorithms (not determined by the signatures):

```text
index(d)       = position of d in Dir::ALL (N=0 … NW=7, clockwise)
eighths(a, b)  = (index(b) - index(a)).rem_euclid(8)            // clockwise steps a → b

toward(from, to):   (dx, dy) = to - from; (0, 0) → N
    12*|dy| < 5*|dx|  → E if dx > 0 else W        // within 22.5° of the row
    12*|dx| < 5*|dy|  → S if dy > 0 else N        // within 22.5° of the column
    else              → the diagonal of sign(dx), sign(dy)

turn_toward(facing, goal):  d = eighths(facing, goal)
    0 → facing;  1..=4 → one eighth clockwise;  5..=7 → one eighth counter-clockwise

aim(at, facing, target):
    the facings f in Dir::ALL with in_field(at, f, target), the one with the fewest
    eighths either way from `facing` (min(d, 8 - d)), clockwise first on a tie;
    none → toward(at, target)
```

fn the_field_is_the_cameras_cone_on_all_eight_facings() {
    let at = Pos::new(10, 10);
    assert!(in_field(at, Dir::E, Pos::new(18, 10)));
    assert!(!in_field(at, Dir::E, Pos::new(19, 10)));
    assert!(in_field(at, Dir::E, Pos::new(12, 12)));
