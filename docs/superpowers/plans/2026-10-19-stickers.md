# Stickers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cosmetic sticker items, stuck on any worn item with a drawing through a third blueprint mode on `s`, with the pawn deck's NO FUTURE and x‿x as real factory stickers.

**Architecture:** `game` gets the sticker item kind, its art as data, `Stuck` stickers on `ItemCopy` and the `Stick`/`Peel` actions, geometry-free. `strata-zero` turns and draws stickers (`ui/stickers.rs`), each drawing declares a `StickerArea` through the `Art` seam, and `screens/stickers.rs` is the mode, beside `screens/bench.rs`, knowing the item only through `Art` and the host copy.

**Tech Stack:** Rust, ratatui (TestBackend for screen tests), serde/RON content.

**Spec:** `docs/superpowers/specs/2026-10-19-stickers-design.md`; art reference `docs/superpowers/specs/2026-10-19-stickers-art.py` (the truth for every pixel, glyph, colour, turn table, area rect and tray offset; run it to print every sticker at every turn).

## Global Constraints

- Fits the minimum terminal, 100×30; tests run at 100×30 and 120×40.
- Every glyph a sticker draws is one cell wide (`unicode-width`), at every turn; every colour is `Color::Rgb`.
- `screens/stickers.rs` knows the item only through `Art` and the host copy: no deck, gun or look names in it. UI text comes from kinds and names, never from the current examples.
- Meatspace only: `Stick` and `Peel` are in `handles_items`; picking and arming a peel are refused jacked in with `JACKED_IN`.
- `game` stays free of geometry: `Stick` never checks the area.
- Never rebuild `target/release/strata` (Jeffrey plays it from the main checkout); this worktree has its own `target/`.
- Each task ends green: `cargo test --workspace`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo fmt --all --check`.
- Commit messages end with:
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` and
  `Claude-Session: https://claude.ai/code/session_014zwgC815q3KaJsaiBuvToz`.
- Existing tests change only for the two documented reasons: the inspect hint gains `s stickers`, and the pawnshop deck is now held per copy (and its painted stickers now come from its copy).

## Review Focus

1. **A stuck sticker that no longer fits** (the drawing changed, or content moved it over a part): it draws clipped to the drawing, can still be pointed at and peeled. Test in Task 6.
2. **The pack's last sticker stuck**: the tray empties, the pointer lands on the new sticker, and the hints drop `↓ tray`. Test in Task 5.
3. **Stickers follow their copy**: stuck on a carried pawnshop deck (`Host::Pack`), then equipped, the worn copy has them; take it off and they come back with it. Test in Task 2.
4. **Jacked in**: arrows still browse the tray and the stuck stickers, but space neither picks nor arms, nothing changes, the log warns. Test in Task 6.
5. **D'SHAWN's 29 stacks at 100×30**: the tray scrolls to keep the pointed tile in view (`‹`/`›` shown), and the risen band never leaves the body. Test in Task 5.
