# Jobs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fixers on their corners hand out seeded jobs (fetch a shard, copy a server or vault, plant a backdoor, deliver a package) with deadlines, pay and a standing; the QUEST pane and the deck read them; the welcome favour becomes the first job.

**Architecture:** A new `jobs` module in `crates/strata-zero` owns the job list, the fixers' standings, generation from the city and the Talk rows. The rest of the app reports events (`Event::Taken/Copied/Planted/Handed`) to it and reads it for display. `Character.quests` and the content quests go; the sim guarantees a fixer per city and learns two readers (`work_hours`, `spot_of`). Voice lives in `flavor/jobs.ron`.

**Tech Stack:** Rust 2024 edition workspace (`citygen`, `game`, `sim`, `strata-zero`), ratatui, ron + serde, `citygen::rng::hash64` for every seeded roll. Tests are `cargo test` unit and integration tests inside the crates.

**Spec:** `docs/superpowers/specs/2026-10-18-jobs-design.md`

## Global Constraints

- Every roll is `citygen::rng::hash64(seed, x)`; no `rand` in `jobs`. Same city, fixer and counter give the same job.
- Constants exactly as the spec's §1 block (`REFUSE_AT = -3`, `COPY_AT = 2`, `PLANT_AT = 4`, `VAULT_AT = 6`, `GAIN_DONE = 1`, `LOSS_DROP = -1`, `LOSS_LATE = -2`, `HOURS_FETCH = 12`, `HOURS_COPY = 24`, `HOURS_PLANT = 24`, `HOURS_DELIVER = 8`, `PAY_FETCH = 200`, `PAY_DELIVER_BASE = 100`, `PAY_COPY_PER_SECURITY = 3`, `PAY_VAULT_PER_SECURITY = 5`, `PAY_PLANT_BASE = 400`, `PAY_PLANT_PER_SECURITY = 2`, `FETCH_RANGE = 80`, `DELIVER_MIN_RANGE = 30`, `WARN_MINUTES = 60`).
- Log lines in the house voice: lower case, `·` separators, names in backticks (`` `<title>` · taken ``). Story lines through `st.story`, refusals through `st.warn`, results through `st.say`.
- All voice text (titles, briefs, the fixer's lines) comes from `flavor/jobs.ron`; no job prose as string literals in Rust except objective texts and log lines.
- A fixer has at most one `Offered` and one `Taken` job at a time; `objectives` always ends with the hand-in.
- Session-only state: `st.jobs` is reset by `enter_city`. Nothing is saved.
- `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace` green at the end of every task. Commit per task with the house commit style (`feat(app): …`, `docs: …`), ending with the attribution lines in the session reminder.
- Never rebuild `target/release/strata`; tests use the default target dir.

## Review Focus

1. A Fetch whose flat is the player's own, or whose building has no lived-in flat: generation must skip it and fall through to another candidate or kind, never lay a shard in the player's bedroom. (Task 4 tests `fetch_never_picks_your_own_flat`.)
2. Handing in a Fetch when the pack holds no `paydata` (sold, dropped, never picked): the row is disabled with `the shard is not on you`, never pays. (Task 6 test `hand_in_refuses_without_the_shard`.)
3. A Deliver package dropped on the ground and picked up again: the hand-over row re-enables, nothing is doubled. (Task 6 test `hand_over_needs_the_package_in_the_pack`.)
4. A deadline passing while jacked in or in a menu: the minute tick is idempotent and fails the job once, one mail, one standing loss, even when many minutes pass in one tick. (Task 2 test `minute_fails_a_late_job_once`, Task 5 test `a_deadline_passing_mails_once`.)
5. A city whose only fixer never comes within reach (no Neon Strip or Night Market): the sim still seeds one, and the first mail still has a sender. (Task 3 test `every_city_has_a_fixer`, Task 4 test `first_favour_on_a_city_without_a_strip`.)

```rust
//! The fixers' voice: titles, briefs and lines, parsed from `flavor/jobs.ron`.

use serde::{Deserialize, Serialize};
use thiserror::Error;

const DEFAULT: &str = include_str!("../../../../flavor/jobs.ron");
const SLOTS: [&str; 11] = ["building", "floor", "number", "how", "host", "security",
    "name", "profession", "place", "hours", "district"];

#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub enum KindTag { Fetch, Copy, Plant, Deliver }

impl KindTag {
    pub const ALL: [KindTag; 4] = [KindTag::Fetch, KindTag::Copy, KindTag::Plant, KindTag::Deliver];
    pub fn label(self) -> &'static str {
        match self { KindTag::Fetch => "fetch", KindTag::Copy => "copy", KindTag::Plant => "plant", KindTag::Deliver => "deliver" }
    }
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Say { Offer, Taken, Handed, Dropped, Late, Refused, Nothing, Receiver }

#[derive(Clone, Debug, Error, PartialEq)]
pub enum FlavorError {
    #[error("jobs parse error: {0}")] Parse(String),
    #[error("jobs: `{0}` is empty")] Empty(String),
    #[error("jobs: {where_}: unknown slot `{{{slot}}}`")] UnknownSlot { where_: String, slot: String },
    #[error("jobs: kind {0:?} has no titles or briefs")] MissingKind(KindTag),
}

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct How { pub card: String, pub server: String }

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct Flavor {
    pub titles: Vec<(KindTag, Vec<String>)>,
    pub briefs: Vec<(KindTag, Vec<Vec<String>>)>,
    pub how: How,
    #[serde(rename = "where")]
    pub where_: String,
    pub offer: Vec<String>,
    pub taken: Vec<String>,
    pub handed: Vec<String>,
    pub dropped: Vec<String>,
    pub late: Vec<String>,
    pub refused: Vec<String>,
    pub nothing: Vec<String>,
    pub receiver: Vec<String>,
}

/// Replaces every `{slot}` that has a value; unknown braces stay as written.
pub fn fill(template: &str, slots: &[(&str, String)]) -> String {
    let mut out = template.to_string();
    for (k, v) in slots {
        out = out.replace(&format!("{{{k}}}"), v);
    }
    out
}

fn pick<'a>(list: &'a [String], roll: u64) -> &'a str {
    list.get((roll % list.len().max(1) as u64) as usize).map_or("", String::as_str)
}

impl Flavor {
    pub fn load() -> Result<Flavor, FlavorError> {
        let f: Flavor = ron::from_str(DEFAULT).map_err(|e| FlavorError::Parse(e.to_string()))?;
        f.validate()?;
        Ok(f)
    }

    pub fn validate(&self) -> Result<(), FlavorError> {
        for (name, list) in [("offer", &self.offer), ("taken", &self.taken), ("handed", &self.handed),
            ("dropped", &self.dropped), ("late", &self.late), ("refused", &self.refused),
            ("nothing", &self.nothing), ("receiver", &self.receiver)] {
            if list.is_empty() { return Err(FlavorError::Empty(name.into())); }
        }
        for k in KindTag::ALL {
            let titles = self.titles.iter().find(|(t, _)| *t == k).map(|(_, l)| l);
            let briefs = self.briefs.iter().find(|(t, _)| *t == k).map(|(_, l)| l);
            match (titles, briefs) {
                (Some(t), Some(b)) if !t.is_empty() && !b.is_empty() => {
                    for s in t { check_slots(&format!("title {k:?}"), s)?; }
                    for lines in b { for s in lines { check_slots(&format!("brief {k:?}"), s)?; } }
                }
                _ => return Err(FlavorError::MissingKind(k)),
            }
        }
        check_slots("where", &self.where_)
    }

    pub fn title(&self, kind: KindTag, roll: u64, slots: &[(&str, String)]) -> String {
        let list = self.titles.iter().find(|(t, _)| *t == kind).map(|(_, l)| l.as_slice()).unwrap_or(&[]);
        fill(pick(list, roll), slots)
    }

    pub fn brief(&self, kind: KindTag, roll: u64, slots: &[(&str, String)]) -> Vec<String> {
        let list = self.briefs.iter().find(|(t, _)| *t == kind).map(|(_, l)| l.as_slice()).unwrap_or(&[]);
        list.get((roll % list.len().max(1) as u64) as usize)
            .map(|lines| lines.iter().map(|l| fill(l, slots)).collect())
            .unwrap_or_default()
    }

    pub fn how_card(&self) -> &str { &self.how.card }
    pub fn how_server(&self) -> &str { &self.how.server }
    pub fn where_line(&self, slots: &[(&str, String)]) -> String { fill(&self.where_, slots) }

    pub fn line(&self, which: Say, roll: u64) -> &str {
        let list = match which {
            Say::Offer => &self.offer, Say::Taken => &self.taken, Say::Handed => &self.handed,
            Say::Dropped => &self.dropped, Say::Late => &self.late, Say::Refused => &self.refused,
            Say::Nothing => &self.nothing, Say::Receiver => &self.receiver,
        };
        pick(list, roll)
    }
}

/// Every `{word}` in `s` must be a known slot.
fn check_slots(where_: &str, s: &str) -> Result<(), FlavorError> {
    let mut rest = s;
    while let Some(start) = rest.find('{') {
        let Some(end) = rest[start..].find('}') else { break };
        let slot = &rest[start + 1..start + end];
        if !SLOTS.contains(&slot) {
            return Err(FlavorError::UnknownSlot { where_: where_.into(), slot: slot.into() });
        }
        rest = &rest[start + end + 1..];
    }
    Ok(())
}
```

```rust
//! Jobs: the work the fixers hand out, their deadlines, and what each fixer thinks
//! of you. Runtime data, never content; the rest of the app reports events here.

pub mod flavor;
pub mod ui;

pub use flavor::*;

use citygen::{BuildingId, Place, Pos};
use game::ItemId;
use sim::PersonId;
use std::collections::BTreeMap;

pub const REFUSE_AT: i32 = -3;
pub const COPY_AT: i32 = 2;
pub const PLANT_AT: i32 = 4;
pub const VAULT_AT: i32 = 6;
pub const GAIN_DONE: i32 = 1;
pub const LOSS_DROP: i32 = -1;
pub const LOSS_LATE: i32 = -2;
pub const HOURS_FETCH: u64 = 12;
pub const HOURS_COPY: u64 = 24;
pub const HOURS_PLANT: u64 = 24;
pub const HOURS_DELIVER: u64 = 8;
pub const PAY_FETCH: u32 = 200;
pub const PAY_DELIVER_BASE: u32 = 100;
pub const PAY_COPY_PER_SECURITY: u32 = 3;
pub const PAY_VAULT_PER_SECURITY: u32 = 5;
pub const PAY_PLANT_BASE: u32 = 400;
pub const PAY_PLANT_PER_SECURITY: u32 = 2;
pub const FETCH_RANGE: i32 = 80;
pub const DELIVER_MIN_RANGE: i32 = 30;
pub const WARN_MINUTES: u64 = 60;

#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord, Hash)]
pub struct JobId(pub u32);

#[derive(Clone, Debug, PartialEq, Eq)]
pub enum Kind {
    Fetch { building: BuildingId, level: i32, number: u16, tile: Pos },
    Copy { building: BuildingId, vault: bool },
    Plant { building: BuildingId },
    Deliver { to: PersonId, item: ItemId },
}

impl Kind {
    pub fn tag(&self) -> KindTag {
        match self {
            Kind::Fetch { .. } => KindTag::Fetch,
            Kind::Copy { .. } => KindTag::Copy,
            Kind::Plant { .. } => KindTag::Plant,
            Kind::Deliver { .. } => KindTag::Deliver,
        }
    }
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum State { Offered, Taken, Done, Failed, Dropped }

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Objective { pub text: String, pub done: bool }

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Job {
    pub id: JobId,
    pub fixer: PersonId,
    pub kind: Kind,
    pub title: String,
    pub brief: Vec<String>,
    pub objectives: Vec<Objective>,
    pub pay: u32,
    pub hours: u64,
    pub offered: u64,
    pub taken: Option<u64>,
    pub deadline: Option<u64>,
    pub state: State,
}

#[derive(Clone, Copy, Debug, Default, PartialEq, Eq)]
pub struct Fixer { pub standing: i32, pub rolled: u32 }

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct Late { pub job: JobId }

#[derive(Clone, Debug, PartialEq, Eq)]
pub enum Event {
    Taken { place: Place, pos: Pos },
    Copied { building: BuildingId, vault: bool },
    Planted { building: BuildingId },
    Handed { job: JobId },
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Change { Ticked { job: JobId, objective: usize } }

#[derive(Default)]
pub struct Jobs {
    pub list: Vec<Job>,
    pub fixers: BTreeMap<PersonId, Fixer>,
    next: u32,
    last_minute: u64,
}

/// The item a hand-in takes from the pack, when the kind brings one back.
pub fn handin_item(kind: &Kind) -> Option<ItemId> {
    match kind {
        Kind::Fetch { .. } | Kind::Copy { vault: false, .. } => Some(ItemId::new("paydata")),
        Kind::Copy { vault: true, .. } => Some(ItemId::new("vault_data")),
        Kind::Plant { .. } | Kind::Deliver { .. } => None,
    }
}

/// Minutes left as the pane says them.
pub fn clock_text(left: u64) -> String {
    match left {
        0 => "late".to_string(),
        m if m < 60 => format!("{m}m"),
        m => format!("{}h {}m", m / 60, m % 60),
    }
}

impl Jobs {
    pub fn push(&mut self, mut job: Job) -> JobId {
        job.id = JobId(self.next);
        self.next += 1;
        let id = job.id;
        self.list.push(job);
        id
    }
    pub fn get(&self, id: JobId) -> Option<&Job> { self.list.iter().find(|j| j.id == id) }
    fn get_mut(&mut self, id: JobId) -> Option<&mut Job> { self.list.iter_mut().find(|j| j.id == id) }
    pub fn standing(&self, fixer: PersonId) -> i32 { self.fixers.get(&fixer).map_or(0, |f| f.standing) }
    pub fn fixer_mut(&mut self, fixer: PersonId) -> &mut Fixer { self.fixers.entry(fixer).or_default() }
    pub fn offered(&self, fixer: PersonId) -> Option<&Job> {
        self.list.iter().find(|j| j.fixer == fixer && j.state == State::Offered)
    }
    pub fn taken(&self, fixer: PersonId) -> Option<&Job> {
        self.list.iter().find(|j| j.fixer == fixer && j.state == State::Taken)
    }
    /// The oldest job in hand: the pane's.
    pub fn active(&self) -> Option<&Job> { self.list.iter().find(|j| j.state == State::Taken) }

    pub fn allowed(standing: i32) -> Vec<KindTag> {
        if standing <= REFUSE_AT { return Vec::new(); }
        let mut out = vec![KindTag::Fetch, KindTag::Deliver];
        if standing >= COPY_AT { out.push(KindTag::Copy); }
        if standing >= PLANT_AT { out.push(KindTag::Plant); }
        out
    }

    pub fn take(&mut self, id: JobId, now: u64) -> bool {
        let Some(j) = self.get_mut(id) else { return false };
        if j.state != State::Offered { return false; }
        j.state = State::Taken;
        j.taken = Some(now);
        j.deadline = Some(now + j.hours * 60);
        true
    }

    pub fn drop_job(&mut self, id: JobId) -> bool {
        let Some(j) = self.get_mut(id) else { return false };
        if j.state != State::Taken { return false; }
        j.state = State::Dropped;
        let fixer = j.fixer;
        self.fixer_mut(fixer).standing += LOSS_DROP;
        true
    }

    /// Ends a Taken job: every objective ticked, the standing up, the pay returned.
    pub fn hand_in(&mut self, id: JobId) -> Option<u32> {
        let j = self.get_mut(id)?;
        if j.state != State::Taken { return None; }
        j.state = State::Done;
        for o in &mut j.objectives { o.done = true; }
        let (fixer, pay) = (j.fixer, j.pay);
        self.fixer_mut(fixer).standing += GAIN_DONE;
        Some(pay)
    }

    pub fn ready(&self, id: JobId, backdoor_stands: &dyn Fn(BuildingId) -> bool, carries: &dyn Fn(&ItemId) -> bool) -> Result<(), String> {
        let j = self.get(id).ok_or_else(|| "no such job".to_string())?;
        if j.state != State::Taken { return Err("not in hand".to_string()); }
        let n = j.objectives.len();
        if j.objectives.iter().take(n.saturating_sub(1)).any(|o| !o.done) {
            return Err(match j.kind {
                Kind::Fetch { .. } | Kind::Copy { .. } => "the shard is not yet yours",
                Kind::Plant { .. } => "no backdoor stands there yet",
                Kind::Deliver { .. } => "the package is not delivered",
            }.to_string());
        }
        if let Kind::Plant { building } = j.kind && !backdoor_stands(building) {
            return Err("the backdoor burned · plant it again".to_string());
        }
        if let Some(item) = handin_item(&j.kind) && !carries(&item) {
            return Err("the shard is not on you".to_string());
        }
        Ok(())
    }

    pub fn on(&mut self, ev: Event) -> Vec<Change> {
        let mut out = Vec::new();
        for j in self.list.iter_mut().filter(|j| j.state == State::Taken) {
            let hit = match (&j.kind, &ev) {
                (Kind::Fetch { building, level, tile, .. }, Event::Taken { place, pos }) => {
                    *place == Place::Floor { building: *building, level: *level } && pos == tile
                }
                (Kind::Copy { building, vault }, Event::Copied { building: b, vault: v }) => building == b && vault == v,
                (Kind::Plant { building }, Event::Planted { building: b }) => building == b,
                (Kind::Deliver { .. }, Event::Handed { job }) => *job == j.id,
                _ => false,
            };
            if hit && let Some(o) = j.objectives.first_mut() && !o.done {
                o.done = true;
                out.push(Change::Ticked { job: j.id, objective: 0 });
            }
        }
        out
    }

    pub fn minute(&mut self, now: u64) -> Vec<Late> {
        if now <= self.last_minute && self.last_minute != 0 { return Vec::new(); }
        self.last_minute = now;
        let mut late = Vec::new();
        let mut losses = Vec::new();
        for j in self.list.iter_mut().filter(|j| j.state == State::Taken) {
            if j.deadline.is_some_and(|d| d < now) {
                j.state = State::Failed;
                late.push(Late { job: j.id });
                losses.push(j.fixer);
            }
        }
        for f in losses { self.fixer_mut(f).standing += LOSS_LATE; }
        late
    }

    pub fn left(job: &Job, now: u64) -> Option<u64> { job.deadline.map(|d| d.saturating_sub(now)) }
}
```

```rust
//! Rolling a job from the city: a flat with a shard, a server, a host, a person.

use super::ui::{district_of_fixer, fixer_name};
use super::{Job, JobId, Jobs, Kind, KindTag, Objective, State, *};
use crate::app::AppState;
use citygen::rng::hash64;
use citygen::{BuildingId, FloorPlan, Place, Pos, RoomKind};
use citygen::construct::{GREY_THRESHOLD, ICE_THRESHOLD};
use citygen::net::NodeKind;
use game::ItemId;
use sim::{PersonId, Work};

const SALT_KIND: u64 = 0x10B_0001;
const SALT_TARGET: u64 = 0x10B_0002;
const SALT_FLAT: u64 = 0x10B_0003;
const SALT_TEXT: u64 = 0x10B_0004;
const SALT_VAULT: u64 = 0x10B_0005;
const FETCH_TRIES: usize = 4;

pub fn roll(seed: u64, fixer: PersonId, counter: u32, salt: u64) -> u64 {
    hash64(seed, (fixer.0 as u64) ^ ((counter as u64) << 32) ^ salt)
}

fn seed_of(st: &AppState) -> u64 { st.city.as_ref().map_or(0, |c| c.seed) }

pub fn fixer_spot(st: &AppState, fixer: PersonId) -> Option<Pos> { st.world.as_ref()?.spot_of(fixer) }

/// The fixer whose corner is nearest `from`.
pub fn nearest_fixer(st: &AppState, from: Pos) -> Option<PersonId> {
    st.world.as_ref()?.people().iter()
        .filter(|p| p.profession == "fixer")
        .filter_map(|p| match p.work { Work::Spot(pos) => Some((pos.manhattan(from), p.id)), _ => None })
        .min_by_key(|(d, id)| (*d, id.0))
        .map(|(_, id)| id)
}

fn door_of(st: &AppState, b: BuildingId) -> Option<Pos> {
    st.city.as_ref()?.portals(b).first().map(|(_, p)| *p)
}

fn has_node(st: &AppState, b: BuildingId, kind: NodeKind) -> bool {
    st.city.as_ref().is_some_and(|c| c.net.nodes.iter().any(|n| n.building == Some(b) && n.kind == kind))
}

fn lived_in(st: &AppState, b: BuildingId) -> bool {
    st.world.as_ref().is_some_and(|w| w.people().iter().any(|p| p.home == Some(b)))
}

pub fn hours_text((from, to): (u16, u16)) -> String {
    format!("{:02}:{:02}–{:02}:{:02}", from / 60, from % 60, to / 60, to % 60)
}

pub fn where_line(st: &AppState, fixer: PersonId) -> String {
    st.flavor.where_line(&[("district", district_of_fixer(st, fixer))])
}

fn blank(fixer: PersonId, kind: Kind, hours: u64, pay: u32, now: u64) -> Job {
    Job { id: JobId(0), fixer, kind, title: String::new(), brief: Vec::new(), objectives: Vec::new(),
          pay, hours, offered: now, taken: None, deadline: None, state: State::Offered }
}

fn handin_text(st: &AppState, fixer: PersonId) -> String {
    format!("Bring it to {} · {} corner · 18:00–04:00", fixer_name(st, fixer), district_of_fixer(st, fixer))
}

/// Lays a shard in a flat of `b` and returns the Fetch kind; `None` when nobody lives there.
fn fetch_in(st: &mut AppState, b: BuildingId, r: u64) -> Option<Kind> {
    crate::credentials::prepare(st, b);
    let own = st.home.map(|h| (h.home.building, h.home.level, h.home.number));
    let flats: Vec<(i32, u16)> = st.interiors.homes_of(b)?.flats()
        .filter(|(l, n)| own != Some((b, *l, *n))).collect();
    if flats.is_empty() { return None; }
    let (level, number) = flats[(r % flats.len() as u64) as usize];
    let city = st.city.as_ref()?;
    let floor = st.interiors.ensure(city, b, level)?;
    let room = floor.rooms.iter().find(|r| r.kind == RoomKind::Flat && r.number == number)?;
    let tile = room.rect.iter().find(|p| floor.tiles[*p].is_walkable() && floor.tiles[*p].feature.is_none())?;
    st.ground.add(Place::Floor { building: b, level }, tile, ItemId::new("paydata"), 1);
    Some(Kind::Fetch { building: b, level, number, tile })
}

fn finish_fetch(st: &AppState, mut job: Job, r_text: u64) -> Job {
    let Kind::Fetch { building, level, number, .. } = job.kind else { return job };
    let name = crate::net::building_name(st, building);
    let how = if has_node(st, building, NodeKind::Server) { st.flavor.how_server() } else { st.flavor.how_card() }.to_string();
    let slots = [("building", name.clone()), ("floor", FloorPlan::label(level)), ("number", number.to_string()), ("how", how)];
    job.title = st.flavor.title(KindTag::Fetch, r_text, &slots);
    job.brief = st.flavor.brief(KindTag::Fetch, r_text, &slots);
    job.objectives = vec![
        Objective { text: format!("Take the shard from {number} on {} of {name}", FloorPlan::label(level)), done: false },
        Objective { text: handin_text(st, job.fixer), done: false },
    ];
    job
}

fn servers_in_band(st: &AppState, standing: i32) -> Vec<BuildingId> {
    let Some(city) = st.city.as_ref() else { return Vec::new() };
    let mut out: Vec<BuildingId> = city.districts.iter().flat_map(|d| crate::access::scannable(st, d.id)).collect();
    out.retain(|b| {
        let s = crate::access::security_of(st, *b);
        if standing < PLANT_AT { s < ICE_THRESHOLD } else if standing < VAULT_AT { s < GREY_THRESHOLD } else { true }
    });
    out
}

pub fn generate(st: &mut AppState, fixer: PersonId, kind: KindTag, counter: u32) -> Option<Job> {
    let seed = seed_of(st);
    let now = st.net.now(st);
    let standing = st.jobs.standing(fixer);
    let r_target = roll(seed, fixer, counter, SALT_TARGET);
    let r_text = roll(seed, fixer, counter, SALT_TEXT);
    let spot = fixer_spot(st, fixer)?;
    match kind {
        KindTag::Fetch => {
            let city = st.city.as_ref()?;
            let mut cands: Vec<BuildingId> = city.buildings.iter()
                .filter(|x| x.kind.is_closed())
                .filter(|x| door_of(st, x.id).is_some_and(|d| d.manhattan(spot) <= FETCH_RANGE))
                .filter(|x| has_node(st, x.id, NodeKind::Server) || lived_in(st, x.id))
                .map(|x| x.id).collect();
            if cands.is_empty() { return None; }
            let start = (r_target % cands.len() as u64) as usize;
            cands.rotate_left(start);
            for (i, b) in cands.into_iter().take(FETCH_TRIES).enumerate() {
                let r_flat = roll(seed, fixer, counter, SALT_FLAT ^ i as u64);
                if let Some(k) = fetch_in(st, b, r_flat) {
                    return Some(finish_fetch(st, blank(fixer, k, HOURS_FETCH, PAY_FETCH, now), r_text));
                }
            }
            None
        }
        KindTag::Copy => {
            let servers = servers_in_band(st, standing);
            if servers.is_empty() { return None; }
            let vault = standing >= VAULT_AT && roll(seed, fixer, counter, SALT_VAULT) % 3 == 0;
            let pool: Vec<BuildingId> = if vault { servers.iter().copied().filter(|b| has_node(st, *b, NodeKind::DataVault)).collect() } else { servers };
            if pool.is_empty() { return None; }
            let b = pool[(r_target % pool.len() as u64) as usize];
            let sec = crate::access::security_of(st, b) as u32;
            let pay = sec * if vault { PAY_VAULT_PER_SECURITY } else { PAY_COPY_PER_SECURITY };
            let host = crate::helix::hosts::building_hostname(st, b);
            let slots = [("host", host.clone()), ("security", sec.to_string())];
            let mut job = blank(fixer, Kind::Copy { building: b, vault }, HOURS_COPY, pay, now);
            job.title = st.flavor.title(KindTag::Copy, r_text, &slots);
            job.brief = st.flavor.brief(KindTag::Copy, r_text, &slots);
            job.objectives = vec![
                Objective { text: format!("Copy {host}'s {}", if vault { "vault" } else { "server" }), done: false },
                Objective { text: handin_text(st, fixer), done: false },
            ];
            Some(job)
        }
        KindTag::Plant => {
            let now_m = now;
            let pool: Vec<BuildingId> = servers_in_band(st, standing).into_iter()
                .filter(|b| st.backdoors.held(*b).is_none() && st.backdoors.can_plant(*b, now_m).is_ok()).collect();
            if pool.is_empty() { return None; }
            let b = pool[(r_target % pool.len() as u64) as usize];
            let sec = crate::access::security_of(st, b) as u32;
            let host = crate::helix::hosts::building_hostname(st, b);
            let slots = [("host", host.clone()), ("security", sec.to_string())];
            let mut job = blank(fixer, Kind::Plant { building: b }, HOURS_PLANT, PAY_PLANT_BASE + sec * PAY_PLANT_PER_SECURITY, now);
            job.title = st.flavor.title(KindTag::Plant, r_text, &slots);
            job.brief = st.flavor.brief(KindTag::Plant, r_text, &slots);
            job.objectives = vec![
                Objective { text: format!("Plant a backdoor on {host}"), done: false },
                Objective { text: format!("Report to {} while it stands", fixer_name(st, fixer)), done: false },
            ];
            Some(job)
        }
        KindTag::Deliver => {
            let world = st.world.as_ref()?;
            let city = st.city.as_ref()?;
            let mine = st.home.and_then(|h| st.interiors.homes_of(h.home.building)?.household_of(h.home.level, h.home.number));
            let pool: Vec<(PersonId, Pos)> = world.people().iter()
                .filter(|p| p.profession != "fixer" && p.id != fixer && Some(p.household) != mine)
                .filter_map(|p| match p.work {

                    Work::Building(b) if city.building_opt(b).is_some_and(|x| x.kind.is_closed()) => Some((p.id, door_of(st, b)?)),
                    _ => None,
                })
                .filter(|(_, pos)| pos.manhattan(spot) >= DELIVER_MIN_RANGE)
                .collect();
            if pool.is_empty() { return None; }
            let (to, at) = pool[(r_target % pool.len() as u64) as usize];
            let p = &world.people()[to.0 as usize];
            let place = match p.work { Work::Building(b) => crate::net::building_name(st, b), _ => "the corner".to_string() };
            let hours = hours_text(world.work_hours(to).unwrap_or((0, 0)));
            let profession = world.card(to, city).profession;
            let slots = [("name", p.name.clone()), ("profession", profession), ("place", place.clone()), ("hours", hours.clone())];

            let mut job = blank(fixer, Kind::Deliver { to, item: ItemId::new("sealed_package") }, HOURS_DELIVER, pay, now);

/// The fixer's standing offer, rolled now if they have none and nothing in hand.
pub fn offer(st: &mut AppState, fixer: PersonId) -> Option<JobId> {
    if let Some(j) = st.jobs.offered(fixer) { return Some(j.id); }
    if st.jobs.taken(fixer).is_some() { return None; }
    let standing = st.jobs.standing(fixer);
    let allowed = Jobs::allowed(standing);
    if allowed.is_empty() { return None; }
    let counter = st.jobs.fixer_mut(fixer).rolled;
    st.jobs.fixer_mut(fixer).rolled += 1;
    let first = (roll(seed_of(st), fixer, counter, SALT_KIND) % allowed.len() as u64) as usize;
    for i in 0..allowed.len() {
        let kind = allowed[(first + i) % allowed.len()];
        if let Some(job) = generate(st, fixer, kind, counter) {
            return Some(st.jobs.push(job));
        }
    }
    None
}
```

```rust
/// The job clock: late jobs fail, the fixer writes.
pub fn tick(st: &mut AppState) {
    let now = st.net.now(st);
    for Late { job } in st.jobs.minute(now) {
        let Some(j) = st.jobs.get(job).cloned() else { continue };
        let fixer = ui::fixer_name(st, j.fixer);
        st.warn(format!("`{}` · too late · {fixer} will hear of it", j.title));
        let line = st.flavor.line(Say::Late, job.0 as u64).to_string();
        st.journal.mails.push(crate::credentials::Mail { from: fixer, subject: format!("{} · late", j.title.to_lowercase()), body: vec![line], read: false, at: now });
    }
}

/// Takes an offered job: the state, the mail, a Deliver's package.
pub fn take_job(st: &mut AppState, id: JobId) -> Result<String, String> {
    let now = st.net.now(st);
    let Some(j) = st.jobs.get(id).cloned() else { return Err("no such job".into()) };
    if !st.jobs.take(id, now) { return Err("not on offer".into()); }
    if let Kind::Deliver { item, .. } = &j.kind { st.character.give(item.clone(), 1); }
    let fixer = ui::fixer_name(st, j.fixer);
    let mut body = j.brief.clone();
    body.push(generate::where_line(st, j.fixer));
    let by = now + j.hours * 60;
    body.push(format!("By {:02}:{:02}.", (by / 60) % 24, by % 60));
    body.push(fixer.clone());
    st.journal.mails.push(crate::credentials::Mail { from: fixer.clone(), subject: j.title.to_lowercase(), body, read: false, at: now });
    let said = st.flavor.line(Say::Taken, id.0 as u64).to_string();
    Ok(format!("`{}` · taken · {fixer}: \u{201c}{said}\u{201d}", j.title))
}
```

```rust
pub fn prepare_offers(st: &mut AppState) {
    let Some(player) = st.player.as_ref() else { return };
    let (place, pos) = (player.place, player.pos);
    let fixers: Vec<PersonId> = pos.neighbors4().into_iter().filter_map(|n| {
        let id = if place.is_street() { st.world.as_ref()?.person_at(n) } else { None }?;   // indoors a fixer is never at a station
        let w = st.world.as_ref()?;
        (w.people()[id.0 as usize].profession == "fixer").then_some(id)
    }).collect();
    for f in fixers {
        if st.jobs.standing(f) > REFUSE_AT && !st.backdoors.fixer_quiet(st.net.now(st)) {
            let _ = crate::jobs::offer(st, f);
        }
    }
}

fn refused(st: &AppState, fixer: PersonId) -> bool {
    st.jobs.standing(fixer) <= REFUSE_AT || st.backdoors.fixer_quiet(st.net.now(st))
}

pub fn rows(st: &AppState, fixer: PersonId) -> Vec<Choice> {
    let (Some(city), Some(world)) = (st.city.as_ref(), st.world.as_ref()) else { return Vec::new() };
    let card = world.card(fixer, city);
    let lines: Vec<Line<'static>> = crate::render::people::card_lines(&card).into_iter().skip(1).collect();
    if refused(st, fixer) {
        let line = st.flavor.line(Say::Refused, fixer.0 as u64).to_string();
        let said = format!("{}: \u{201c}{line}\u{201d}", card.name);
        return vec![Choice::new('t', "Talk", Pick::Talk { lines: vec![plain(line)], said })];
    }
    let said = format!("{}: \u{201c}{}\u{201d}", card.name, card.line);
    let mut out = vec![Choice::new('t', "Talk", Pick::Talk { lines, said })];
    if let Some(j) = st.jobs.taken(fixer) {
        let stands = |b: BuildingId| st.backdoors.standing().any(|d| d.building == b);
        let carries = |i: &ItemId| st.character.count(i) > 0;
        match st.jobs.ready(j.id, &stands, &carries) {
            Ok(()) => out.push(Choice::on('h', "Hand in", j.title.clone(), CYAN, Pick::HandIn(j.id)).tail(format!(" · ¤{}", j.pay))),
            Err(why) => out.push(Choice { enabled: false, ..Choice::on('h', "Hand in", j.title.clone(), CYAN, Pick::Close).tail(format!(" · {why}")) }),
        }
        out.push(Choice::on('d', "Drop", j.title.clone(), TEXT, Pick::DropAsk(j.id)));
    } else if let Some(j) = st.jobs.offered(fixer) {
        out.push(Choice::on('w', "Work", j.title.clone(), CYAN, Pick::Offer(j.id)).tail(format!(" · ¤{} · {}h", j.pay, j.hours)));
    } else {
        let line = st.flavor.line(Say::Nothing, fixer.0 as u64);
        out.push(Choice::disabled('w', "Work").tail(format!(" · {line}")));
    }
    out
}

pub fn offer_popup(st: &AppState, id: JobId, tick: u64) -> Popup {
    let Some(j) = st.jobs.get(id) else { return Popup::verbs("", vec![], tick) };
    let subtitle = format!("pay ¤{} · {} hours · {}", j.pay, j.hours, j.kind.tag().label());
    let mut body = vec![format!("\u{201c}{}\u{201d}", st.flavor.line(Say::Offer, id.0 as u64))];
    body.extend(j.brief.iter().cloned());
    Popup::about(Some(Header::title(&j.title)), Some(subtitle),
        vec![Choice::new('y', "Take the job", Pick::Take(id)), Choice::new('n', "Not now", Pick::Close)], tick)
        .with_body(body)
}

pub fn drop_confirm(id: JobId, title: &str, tick: u64) -> Popup {
    Popup::verbs(&format!("Drop {title}?"), vec![Choice::new('y', "Drop it", Pick::Drop(id)), Choice::new('n', "Keep it", Pick::Close)], tick)
}

pub fn hand_in(st: &mut AppState, id: JobId) -> Result<String, String> {
    let j = st.jobs.get(id).cloned().ok_or("no such job")?;
    let stands = |b: BuildingId| st.backdoors.standing().any(|d| d.building == b);
    let carries = |i: &ItemId| st.character.count(i) > 0;
    st.jobs.ready(id, &stands, &carries)?;
    if let Some(item) = handin_item(&j.kind) { game::remove_from_pack(&mut st.character, &item, 1); }
    let pay = st.jobs.hand_in(id).ok_or("not in hand")?;
    st.character.credits = st.character.credits.saturating_add(pay);
    let fixer = fixer_name(st, j.fixer);
    let said = st.flavor.line(Say::Handed, id.0 as u64).to_string();
    let line = format!("`{}` · handed in · ¤{pay} · {fixer}: \u{201c}{said}\u{201d}", j.title);
    st.story(line.clone());
    Ok(line)
}

pub fn drop(st: &mut AppState, id: JobId) -> Result<String, String> {
    let j = st.jobs.get(id).cloned().ok_or("no such job")?;
    if !st.jobs.drop_job(id) { return Err("not in hand".into()); }
    let fixer = fixer_name(st, j.fixer);
    let said = st.flavor.line(Say::Dropped, id.0 as u64).to_string();
    let line = format!("`{}` · dropped · {fixer}: \u{201c}{said}\u{201d}", j.title);
    st.warn(line.clone());
    Ok(line)
}

pub fn receiver_rows(st: &AppState, person: PersonId) -> Vec<Choice> {
    let Some(j) = st.jobs.list.iter().find(|j| j.state == State::Taken && matches!(j.kind, Kind::Deliver { to, .. } if to == person) && !j.objectives[0].done) else { return Vec::new() };
    let Kind::Deliver { item, .. } = &j.kind else { return Vec::new() };
    let name = st.content.item(item).map(|i| i.name.clone()).unwrap_or_else(|| "Package".into());
    if st.character.count(item) > 0 {
        vec![Choice::on('h', "Hand over", name, AMBER, Pick::Hand(j.id))]
    } else {
        vec![Choice { enabled: false, ..Choice::on('h', "Hand over", name, AMBER, Pick::Close).tail(" · not on you") }]
    }
}

pub fn hand_over(st: &mut AppState, id: JobId) -> Result<String, String> {
    let j = st.jobs.get(id).cloned().ok_or("no such job")?;
    let Kind::Deliver { to, item } = j.kind.clone() else { return Err("not a delivery".into()) };
    if j.state != State::Taken || j.objectives[0].done { return Err("already delivered".into()); }
    if st.character.count(&item) == 0 { return Err("the package is not on you".into()); }
    game::remove_from_pack(&mut st.character, &item, 1);
    crate::jobs::send(st, Event::Handed { job: id });
    let (Some(city), Some(world)) = (st.city.as_ref(), st.world.as_ref()) else { return Err("no city".into()) };
    let name = world.card(to, city).name;
    let said = st.flavor.line(Say::Receiver, id.0 as u64).to_string();
    let fixer = fixer_name(st, j.fixer);
    let line = format!("`{name}` takes the package · \u{201c}{said}\u{201d} · {fixer} owes you");
    st.story(line.clone());
    Ok(line)
}
```
