# The Keyjack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every build gets through a flat's door with the Keyjack, a clip-on timing game whose fuse is a mod; Net jobs go only to runners with a deck (#6).

**Architecture:** The Keyjack and its fuses are content (`flavor/content.ron`) on the existing item, hardware, socket and recipe model; its drawings sit beside the Ratchet's (`ui/looks/`, `ui/hardware/`), with the blueprint window picking a look's back in modding mode. The game's numbers are `flavor/keyjack.ron`, read by a small `keyjack` module that turns a lock, a fuse and the runner's skills into a run's parameters. The run itself lives on the keypad screen, opening or locking the door through new `credentials` paths.

**Tech Stack:** Rust (crates `game`, `strata-zero`), ratatui, RON content, serde saves.

**Spec:** `docs/superpowers/specs/2026-11-07-keyjack-design.md`

## Global Constraints

- Build and test into `--target-dir target/smoke` (relative to the worktree), never `target/`. Check both front ends (`CLAUDE.md` "Building and checking").
- Saved types: `#[serde(default)]` on every new field; no `HashSet`, `Rc`, `Cell`, `Instant`, `&'static str`; `runs/fixtures/` keep opening and are never regenerated.
- Every number of the game in `flavor/keyjack.ron` (bar 18; zones R1 `[8,6,5,4]`, R2 `[7,5,3,3]`, R3 `[6,4,3,2]`; speeds `[9,11,13,15]` cells/s; faults 3; Lockpick zones +1; Skeleton key faults +1; ratings street 1, municipal 2, neon 2, megacorp 3). Fuse bonuses on the fuses' mods in `content.ron`: ceramic `Faults(1)`, slow-blow `Sweep(75)`, wideband `Zone(1)`; stock no mod ("no bonus").
- Copy: `k  clip the keyjack`; `k  keyjack · no fuse`; log *"No fuse in the Keyjack."*; *"The Keyjack's fuse blew. The pad locked for 30m."* (the minutes from `LOCKOUT_MINUTES`); code source `Keyjack`, read "cracked with the Keyjack"; ladder "needs a deck".
- Only box-drawing, block and the symbols the game already draws (`every_drawn_character_has_a_glyph`).
- A change a player sees updates its `manual/` chapter in the same branch.
- Commit messages record decisions, no chat; every commit ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; the commit that finishes #6 ends with `Closes #6` before that line. No merge, no push.

## Review Focus

- A run started on a pad that locks mid-run (the lockout of an earlier miss elsewhere does not apply; the pad's own lockout can't start mid-run since `k` is refused while locked) — a fault on the last allowed count must lock exactly once and remove exactly the fitted fuse, never a pack fuse (Task 3 test).
- Clipping on with two Keyjacks, the first fuse-less: the one with a fuse runs; a blown run burns that one's fuse (Task 3 test).
- A save while faults sit on a door, reopened: the faults are back; a lockout that ended while away clears them (Task 2 test).
- The kit on a build whose kit has no socketed item for the fuses: they go in the pack (Task 1 test).
- Ratings out of the data file's range or an unknown device theme: rating 1, never a panic (Task 2 test).
