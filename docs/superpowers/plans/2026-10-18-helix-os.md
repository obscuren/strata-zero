# HELIX/OS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every machine in the city runs a small Unix: a per-host filesystem with users and permissions, a shell with the usual commands, pipes and redirects, the building as `/dev` and the district as `/net`, the old verbs as programs, a persistent home on your rig, and a nano clone.

**Architecture:** A new `helix` module in the app crate: `vfs.rs` (pure tree, paths, permissions), `gen.rs` (hosts generated from the seed, lore from content), `shell.rs` (parser, pipes, redirects, builtins), `bin.rs` (the world as devices and programs over the app state), `nano.rs` (the editor). The terminal screen hosts a `Shell` and optionally a `Nano`. `access.rs` keeps the tier rules and the world actions and loses its verb table.

**Tech Stack:** Rust 2024, ratatui, the workspace crates. `cargo test -p strata-zero`, `cargo clippy --workspace --all-targets -- -D warnings`.

**Spec:** `docs/superpowers/specs/2026-10-18-helix-os-design.md` — read it first; it has the tree, the device semantics, the permission rules and the wording.

## Global Constraints

- Never rebuild `target/release/strata`.
- Commit messages in the repo's voice: `feat(app): ...`, lower case, a sentence.
- Unix wording for errors, exactly: `No such file or directory`, `Not a directory`, `Is a directory`, `Permission denied`, `File exists`, `Directory not empty`; `helix: <cmd>: command not found`.
- The shell is lower case; it never upper-cases input or output. Program replies in the period voice stay upper case.
- Determinism: everything generated comes from `city.seed` and ids through `citygen::rng::hash64`; no `rand`.
- Module layout: `crates/strata-zero/src/helix/{mod.rs,vfs.rs,gen.rs,shell.rs,bin.rs,nano.rs}`, `mod helix;` in `main.rs`.
- Run `cargo fmt -p strata-zero` before every commit.

## Review Focus

1. A guest `cat` of another user's home must say `Permission denied` and reveal nothing, including via `grep`, `head`, `cp` and `nano`. Pinned in Tasks 1, 2 and 5.
2. `rm -r /` and `rm` of `/dev` or `/bin` must be refused (root-owned, and the root dir is never removable). Pinned in Task 1.
3. A host visited twice (or `ssh` out and back) keeps the files you wrote. Pinned in Task 4.
4. Reading a notes file as a resident learns the code once, not on every `cat`, and never from a file you could not read. Pinned in Task 3.
5. Nano on a device file (`/dev/door`, `journal.txt`) must refuse to save with the device's own error and never panic. Pinned in Task 5.

```rust
pub const ROOT: &str = "root"; pub const GUEST: &str = "guest"; pub const USERS: &str = "users";
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub struct Mode { pub owner_r: bool, pub owner_w: bool, pub other_r: bool, pub other_w: bool }
impl Mode { pub const RW_R: Mode; pub const RW_RW: Mode; pub const RW_NONE: Mode; pub const R_R: Mode; }   // "rw-r--", "rw-rw-", "rw----", "r--r--"
#[derive(Clone, Debug, PartialEq, Eq)] pub enum Dev { Door, Lift, Cam(usize), Alarm, Plan, AuthLog, NetLog, Journal, Mail(usize), NetHost(citygen::BuildingId), Passwd }
#[derive(Clone, Debug, PartialEq, Eq)] pub enum Kind { Dir(BTreeMap<String, usize>), File(String), Dev(Dev) }
#[derive(Clone, Debug, PartialEq, Eq)] pub struct Node { pub name: String, pub kind: Kind, pub owner: String, pub mode: Mode }
#[derive(Clone, Debug, PartialEq, Eq)] pub enum VfsError { NotFound, NotADirectory, IsADirectory, Denied, Exists, NotEmpty }
impl std::fmt::Display for VfsError  // the Unix words
#[derive(Clone, Debug, PartialEq, Eq)] pub struct Vfs { nodes: Vec<Node> }
impl Vfs {
    pub fn new() -> Vfs;                                    // "/" owned by root, rw-r--
    pub fn resolve(&self, cwd: &str, home: &str, path: &str) -> Result<usize, VfsError>;
    pub fn normalize(cwd: &str, home: &str, path: &str) -> String;   // the absolute path string, no I/O
    pub fn node(&self, id: usize) -> &Node;
    pub fn path_of(&self, id: usize) -> String;
    pub fn can_read(&self, id: usize, user: &str) -> bool;
    pub fn can_write(&self, id: usize, user: &str) -> bool;
    pub fn mkdir(&mut self, user: &str, cwd: &str, home: &str, path: &str, parents: bool) -> Result<usize, VfsError>;
    pub fn mkdir_as(&mut self, path: &str, owner: &str, mode: Mode) -> usize;   // generator use: no checks, creates parents
    pub fn write(&mut self, user: &str, cwd: &str, home: &str, path: &str, text: &str, append: bool) -> Result<(), VfsError>;
    pub fn put(&mut self, path: &str, text: &str, owner: &str, mode: Mode);     // generator use, no checks
    pub fn put_dev(&mut self, path: &str, dev: Dev, owner: &str, mode: Mode);
    pub fn read(&self, user: &str, cwd: &str, home: &str, path: &str) -> Result<&Kind, VfsError>;   // Denied/IsADirectory as appropriate
    pub fn list(&self, user: &str, cwd: &str, home: &str, path: &str) -> Result<Vec<usize>, VfsError>;  // sorted by name
    pub fn remove(&mut self, user: &str, cwd: &str, home: &str, path: &str, recursive: bool) -> Result<(), VfsError>;
    pub fn copy(&mut self, user: &str, cwd: &str, home: &str, src: &str, dst: &str) -> Result<(), VfsError>;   // files only; dst may be a dir
    pub fn rename(&mut self, user: &str, cwd: &str, home: &str, src: &str, dst: &str) -> Result<(), VfsError>;
    pub fn long_row(&self, id: usize) -> String;    // "drw-r-- root        /etc" style: type char, owner bits, other bits, owner padded to 10, size for files, name
    pub fn size(&self, id: usize) -> usize;
}
```
Rules: `root` may everything; `/` cannot be removed; removing needs write on the parent; a non-empty dir without `recursive` is `NotEmpty`; `write` to a new file needs write on the parent and creates `File` owned by the user with `Mode::RW_R`; writing a `Dev` node through `write` returns `Ok(())` only if `can_write` (the caller handles devices; the vfs just checks); `read` of a `Dev` returns `Ok(&Kind::Dev(..))` if readable.

```rust
#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)] pub enum HostId { Rig, Building(citygen::BuildingId), District(citygen::DistrictId) }
#[derive(Clone, Debug, PartialEq, Eq)] pub struct Shell { pub host: HostId, pub origin: HostId, pub user: String, pub home: String, pub cwd: String, pub history: Vec<String> }
#[derive(Clone, Debug, Default, PartialEq, Eq)] pub struct Output { pub lines: Vec<String>, pub status: i32, pub clear: bool, pub exit: bool, pub denied: bool, pub open_nano: Option<String> }
/// What the shell needs from the world; the app implements it in Task 4, tests use `MemIo`.
pub trait Io {
    fn fs(&mut self, host: HostId) -> &mut Vfs;
    fn hostname(&self, host: HostId) -> String;
    fn os_version(&self, host: HostId) -> String;            // "4.1"
    fn read_dev(&mut self, host: HostId, dev: &Dev, user: &str) -> Result<Vec<String>, String>;   // Err is a full message
    fn write_dev(&mut self, host: HostId, dev: &Dev, user: &str, text: &str) -> Result<Vec<String>, String>;
    fn program(&mut self, shell: &mut Shell, name: &str, args: &[String], stdin: &[String]) -> Option<Result<Output, String>>;  // None: not a program
    fn programs(&self) -> Vec<&'static str>;                 // for /bin and completion
    fn who(&mut self, host: HostId) -> Vec<String>;
}
pub struct MemIo { pub fs: HashMap<HostId, Vfs> }   // test double: devices read "dev:<name>", writes echo back, no programs
pub fn parse(line: &str) -> Result<Vec<Pipeline>, String>;   // `;` → Vec<Pipeline>; Pipeline { stages: Vec<Vec<String>>, redirect: Option<(String, bool /*append*/)> }
pub fn run(io: &mut dyn Io, shell: &mut Shell, line: &str) -> Output;
pub fn complete(io: &mut dyn Io, shell: &Shell, head: &str, word: &str) -> Vec<String>;
pub fn prompt(io: &dyn Io, shell: &Shell) -> String;    // user@host:cwd$  (~ for home, # for root)
pub const BUILTINS: &[&str] = &["ls","cd","pwd","cat","echo","touch","mkdir","rm","cp","mv","grep","head","tail","wc","man","help","whoami","who","uname","hostname","history","clear","exit","nano"];
```
Behaviour per the spec's Shell section. `nano <file>` sets `open_nano = Some(abs path)` and nothing else. Devices: `cat` of a `Dev` calls `io.read_dev`; a redirect onto a `Dev` calls `io.write_dev` with the joined lines; both only after the vfs permission check (`Permission denied` with the Unix message `cat: /dev/alarm: Permission denied` / `helix: /dev/alarm: Permission denied`). `man` has a one-paragraph page for every builtin and program name (a static table; unknown → `No manual entry for x`). `exit` sets `exit = true` (Task 4 decides between returning from ssh and leaving). `uname` prints `HELIX/OS`, `uname -a` prints `HELIX/OS <version> <hostname>`.
