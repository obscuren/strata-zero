# Play HUD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Frame the map screen with a header, resource bars, a sidebar of toggleable sections and an action bar, and turn the fading status line into a message log.

**Architecture:** Pure drawing functions in `ui/hud.rs` (header, bars, action bar) and `ui/sidebar.rs` (sections, budget) are fed by small view structs the map screen fills in. The app state gains a `MessageLog` that replaces `Status`, and `Sidebar` flags that a VIEW popup toggles. The game crate gains level, xp and focus on the character.

**Tech Stack:** Rust 2024, ratatui, crossterm, ron; tests with `TestBackend` buffers.

**Spec:** `docs/superpowers/specs/2026-10-13-play-hud-design.md`

## Global Constraints

- Minimum terminal 100 by 30; the frame must fit at that size in both modes.
- Sidebar panel exactly 30 columns wide (28 inside); never changes width.
- Tick rate 30 per second: cooldown seconds are `left.div_ceil(30)`; `RECENT_TICKS` 90; `TICKS_PER_MINUTE` 90; clock starts at 22:00.
- Bars are 12 cells, `█` filled and `░` empty; filled count `round(12 * cur / max)`, 0 when max is 0.
- Log cap 200 entries; markers `! ` for Warn and `▸ ` for Story.
- Section list order: here, quest, map, log, inspect, legend; defaults on, on, on, on, off, off.
- Action bar: 5 slots; ability names lower-cased and cut to 10 characters with `…`.
- `xp_to_next(level) = 200 * level`; starter `level: 1`, `focus: 30`.
- Every commit ends with the session's attribution lines; `cargo fmt` and `cargo clippy --all-targets -- -D warnings` clean before each commit.
- Text cut with `…`, never overflowing its area.

## Review Focus

1. A 100 by 30 terminal in dev mode with all six sections on must still draw the action bar and never panic (Task 5 `frame_fits_at_minimum_with_every_section`).
2. An ability named longer than ten characters must be cut so the right-hand hints keep their place (Task 3 `action_bar_cuts_long_names`).
3. A log entry wider than the panel wraps and counts as a whole entry in the LOG budget (Task 4 `log_wraps_long_entries_whole`).
4. A very long location on a 100-column header must leave the clock at the right edge (Task 3 `header_keeps_the_clock_when_the_location_is_long`).
5. MESSAGES with an empty log shows `nothing yet`, `0 entries`, and the scroll keys do nothing (Task 6 `messages_popup_handles_an_empty_log`).

```rust
//! The message log: what happened, newest last.

use std::collections::VecDeque;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Kind {
    /// A plain result.
    Info,
    /// A refusal; magenta with a leading `!`.
    Warn,
    /// Quest and level lines; accent with a leading `▸`.
    Story,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Entry {
    pub text: String,
    pub kind: Kind,
    /// The tick the entry arrived.
    pub tick: u64,
}

impl Entry {
    /// The text with its kind's marker in front.
    pub fn marked(&self) -> String {
        match self.kind {
            Kind::Info => self.text.clone(),
            Kind::Warn => format!("! {}", self.text),
            Kind::Story => format!("▸ {}", self.text),
        }
    }
}

#[derive(Clone, Debug, Default)]
pub struct MessageLog {
    entries: VecDeque<Entry>,
}

impl MessageLog {
    pub const CAP: usize = 200;
    /// How long the newest entry counts as recent.
    pub const RECENT_TICKS: u64 = 90;

    pub fn push(&mut self, kind: Kind, text: impl Into<String>, tick: u64) {
        if self.entries.len() == Self::CAP {
            self.entries.pop_front();
        }
        self.entries.push_back(Entry { text: text.into(), kind, tick });
    }

    /// The newest entry, however old.
    pub fn latest(&self) -> Option<&Entry> {
        self.entries.back()
    }

    /// The newest entry while it is younger than `RECENT_TICKS`.
    pub fn recent(&self, tick: u64) -> Option<&Entry> {
        self.latest()
            .filter(|e| tick.saturating_sub(e.tick) < Self::RECENT_TICKS)
    }

    /// Oldest first.
    pub fn iter(&self) -> impl DoubleEndedIterator<Item = &Entry> {
        self.entries.iter()
    }

    pub fn len(&self) -> usize {
        self.entries.len()
    }

    pub fn is_empty(&self) -> bool {
        self.entries.is_empty()
    }
}
```

```rust
//! The play HUD's single rows: header, bars and the action bar.

use crate::anim::effects::pulse;
use crate::render::overlay::Digital;
use crate::ui::chrome::{CYAN, DIM, TEXT};
use citygen::{City, Pos, StratumKind, SubnetOwner};
use ratatui::style::{Color, Modifier, Style};
use ratatui::text::{Line, Span};

pub const BAR_CELLS: usize = 12;
pub const SLOTS: usize = 5;
pub const AMBER: Color = Color::Rgb(255, 200, 80);
pub const GREEN: Color = Color::Rgb(80, 230, 120);
const DIM_AMBER: Color = Color::Rgb(190, 150, 60);
const BADGE_FG: Color = Color::Rgb(10, 11, 16);

/// Cuts `s` to `max` cells, ending in `…` when it was longer.
pub fn cut(s: &str, max: usize) -> String {
    if s.chars().count() <= max {
        return s.to_string();
    }
    if max == 0 {
        return String::new();
    }
    let mut out: String = s.chars().take(max - 1).collect();
    out.push('…');
    out
}

pub struct Header<'a> {
    pub dev: bool,
    pub level: u8,
    pub credits: u32,
    pub location: &'a str,
    pub seed: u64,
    pub fps: Option<f32>,
    pub clock: (u8, u8),
}

/// Left: badge, level, credits. Centre: the location. Right: dev readouts and the clock.
pub fn header(h: &Header, width: u16) -> Line<'static> {
    let w = width as usize;
    let mut spans = vec![Span::raw(" ")];
    if h.dev {
        spans.push(Span::styled(" DEV ", Style::default().fg(BADGE_FG).bg(AMBER).add_modifier(Modifier::BOLD)));
        spans.push(Span::raw(" "));
    }
    spans.push(Span::styled(format!("LVL {}   ¤ {}", h.level, h.credits), Style::default().fg(TEXT).add_modifier(Modifier::BOLD)));
    let used: usize = spans.iter().map(|s| s.width()).sum();
    let mut right = String::new();
    if h.dev {
        right.push_str(&format!("seed {} · ", h.seed));
        if let Some(fps) = h.fps {
            right.push_str(&format!("{fps:.0} fps · "));
        }
    }
    let clock = format!("{:02}:{:02}", h.clock.0, h.clock.1);
    let right_w = right.chars().count() + clock.chars().count() + 1;
    let room = w.saturating_sub(used + right_w);
    let centre = cut(h.location, room.saturating_sub(2));
    let cw = centre.chars().count();

/// Filled cells for `cur` of `max`.
pub fn bar_cells(cur: u32, max: u32) -> usize {
    if max == 0 {
        return 0;
    }
    ((BAR_CELLS as f64 * cur.min(max) as f64 / max as f64).round() as usize).min(BAR_CELLS)
}

/// Green above half, amber above a quarter, pulsing magenta at a quarter or below.
pub fn hp_colour(cur: u32, max: u32, tick: u64) -> Color {
    let frac = if max == 0 { 0.0 } else { cur as f32 / max as f32 };
    if frac > 0.5 {
        GREEN
    } else if frac > 0.25 {
        AMBER
    } else {
        let f = 0.6 + 0.4 * pulse(tick, 20);
        Color::Rgb((255.0 * f) as u8, 0, (200.0 * f) as u8)
    }
}

fn bar(label: &str, cur: u32, max: u32, colour: Color) -> Vec<Span<'static>> {
    let filled = bar_cells(cur, max);
    vec![
        Span::styled(format!("{label} "), Style::default().fg(DIM)),
        Span::styled("█".repeat(filled), Style::default().fg(colour)),
        Span::styled("░".repeat(BAR_CELLS - filled), Style::default().fg(colour).add_modifier(Modifier::DIM)),
        Span::styled(format!(" {cur}/{max}"), Style::default().fg(TEXT)),
    ]
}

}

        BarMode::Walk(slots) => {

                    spans.push(Span::raw("   "));
                }
                match slots.get(i) {
                    Some(slot) => {
                        spans.push(Span::styled(format!("{} ", i + 1), Style::default().fg(CYAN).add_modifier(Modifier::BOLD)));
                        spans.push(Span::styled(cut(&slot.name.to_lowercase(), 10), Style::default().fg(TEXT)));
                        match slot.state {
                            SlotState::Ready => spans.push(Span::styled(" ●", Style::default().fg(CYAN))),
                            SlotState::Cooling(secs) => spans.push(Span::styled(format!(" {secs}s"), Style::default().fg(DIM))),
                        }
                    }
                    None => spans.push(Span::styled(format!("{} ──", i + 1), Style::default().fg(DIM))),
                }
            }
        }
        BarMode::Explore => spans.push(Span::styled("w walk   r regen   g configure", Style::default().fg(TEXT))),
    }
    let right = if dev { ": console   tab deck   ? keys" } else { "tab deck   ? keys" };
    let used: usize = spans.iter().map(|s| s.width()).sum();
    let gap = (width as usize).saturating_sub(used + right.chars().count() + 1);
    spans.push(Span::raw(" ".repeat(gap)));
    spans.push(Span::styled(right.to_string(), Style::default().fg(DIM)));
    spans.push(Span::raw(" "));
    Line::from(spans)
}

/// Where a tile is, for the header: `Kowloon Noodle · Street`, `Helix Biotek · Net`.
pub fn location(city: &City, stratum: StratumKind, pos: Pos) -> String {
    if stratum == StratumKind::Net {
        let owner = Digital::node_under(city, stratum, pos)
            .map(|id| city.net.node(id))
            .map(|n| match city.net.subnet(n.subnet).owner {
                SubnetOwner::Building(b) => {
                    let b = city.building(b);
                    b.name.clone().unwrap_or_else(|| b.kind.label().to_string())
                }
                SubnetOwner::District(d) => city.district(d).name.clone(),
                SubnetOwner::City => city.name.clone(),
            })
            .unwrap_or_else(|| city.name.clone());
        return format!("{owner} · Net");
    }
    let tile = city.tile(stratum, pos);
    let place = tile
        .and_then(|t| t.building)
        .and_then(|b| city.building_opt(b))
        .and_then(|b| b.name.clone())
        .or_else(|| {
            tile.and_then(|t| t.district)
                .and_then(|d| city.district_opt(d))
                .map(|d| d.name.clone())
        })
        .unwrap_or_else(|| "the outskirts".to_string());
    format!("{place} · {}", stratum.label())
}
```

```rust
const QUEST_CAP: u16 = 4;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Section {
    Here,
    Quest,
    Map,
    Log,
    Inspect,
    Legend,
}

impl Section {
    pub const ALL: [Section; 6] = [Section::Here, Section::Quest, Section::Map, Section::Log, Section::Inspect, Section::Legend];

    pub fn label(self) -> &'static str {
        match self {
            Section::Here => "here",
            Section::Quest => "quest",
            Section::Map => "map",
            Section::Log => "log",
            Section::Inspect => "inspect",
            Section::Legend => "legend",
        }
    }

    pub fn dev_only(self) -> bool {
        matches!(self, Section::Inspect | Section::Legend)
    }

    fn index(self) -> usize {
        Section::ALL.iter().position(|s| *s == self).expect("listed")
    }
}

/// Which sections are on; lives in the app state so popups can toggle them.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Sidebar {
    on: [bool; 6],
}

impl Default for Sidebar {
    fn default() -> Self {
        Sidebar { on: [true, true, true, true, false, false] }
    }
}

impl Sidebar {
    pub fn is_on(&self, s: Section) -> bool {
        self.on[s.index()]
    }

    pub fn set(&mut self, s: Section, on: bool) {
        self.on[s.index()] = on;
    }

    pub fn toggle(&mut self, s: Section) {
        let i = s.index();
        self.on[i] = !self.on[i];
    }

    /// Turns the dev-only sections off.
    pub fn leave_dev(&mut self) {
        for s in Section::ALL {
            if s.dev_only() {
                self.set(s, false);
            }
        }
    }

    /// The sections to draw, in order; dev sections only in dev mode.
    pub fn active(&self, dev: bool) -> Vec<Section> {
        Section::ALL.into_iter().filter(|s| self.is_on(*s) && (dev || !s.dev_only())).collect()
    }
}

/// Rows per section, in order. Each non-LOG section takes the smaller of its need and
/// what is left; LOG takes the remainder; MAP drops when LOG would get under three rows.
pub fn budget(needs: &[(Section, u16)], height: u16) -> Vec<(Section, u16)> {
    let mut needs: Vec<(Section, u16)> = needs.to_vec();
    loop {
        let mut left = height;
        let mut rows: Vec<(Section, u16)> = Vec::with_capacity(needs.len());
        for (s, n) in &needs {
            if *s == Section::Log {
                rows.push((*s, 0));
                continue;
            }
            let r = (*n).min(left);
            left -= r;
            rows.push((*s, r));
        }
        let has_log = needs.iter().any(|(s, _)| *s == Section::Log);
        let has_map = needs.iter().any(|(s, _)| *s == Section::Map);
        if has_log && left < LOG_MIN && has_map {
            needs.retain(|(s, _)| *s != Section::Map);
            continue;
        }
        if let Some(r) = rows.iter_mut().find(|(s, _)| *s == Section::Log) {
            r.1 = left;
        }
        rows.retain(|(_, r)| *r > 0);
        return rows;
    }
}

/// `── TITLE ───…` padded to `width`.
fn rule(title: &str, width: u16) -> Line<'static> {
    let head = format!("── {title} ");
    let n = (width as usize).saturating_sub(head.chars().count());
    Line::from(vec![
        Span::styled("── ", Style::default().fg(RULE)),
        Span::styled(format!("{title} "), Style::default().fg(CYAN).add_modifier(Modifier::BOLD)),
        Span::styled("─".repeat(n), Style::default().fg(RULE)),
    ])
}

/// The focus tile: its feature, then what lies on it.
pub fn here_lines(v: &SidebarView) -> Vec<Line<'static>> {
    let city = v.city;
    let mut out = Vec::new();
    if v.stratum == StratumKind::Net {
        if let Some(id) = Digital::node_under(city, v.stratum, v.focus) {
            out.push(plain(format!("◆ {}", city.net.node(id).kind.label())));
        }
    } else if let Some(t) = city.tile(v.stratum, v.focus)
        && t.feature == Some(Feature::Node(NodeKind::Terminal))
    {
        out.push(plain(format!("╥ {}", port_name(city, v.focus))));
    }
    for c in city.connectors_at(v.focus).filter(|c| c.kind != ConnectorKind::Jack) {
        let Some((below, above)) = c.serves_from(v.stratum) else { continue };
        if above.is_some() {
            out.push(plain(format!("> {} up", c.kind.label())));
        }
        if below.is_some() {
            out.push(plain(format!("< {} down", c.kind.label())));
        }
    }
    let stacks = v.ground.at(v.stratum, v.focus);
    for s in stacks.iter().take(ITEM_ROWS) {
        let (name, icon) = match v.content.item(&s.item) {
            Some(i) => (i.name.clone(), kind_icon(i.kind)),
            None => (s.item.to_string(), '?'),
        };
        let qty = if s.qty > 1 { format!(" ×{}", s.qty) } else { String::new() };
        out.push(plain(format!("{icon} {name}{qty}")));
    }
    if stacks.len() > ITEM_ROWS {
        out.push(dim(format!("… and {} more", stacks.len() - ITEM_ROWS)));
    }
    if out.is_empty() {
        out.push(dim("nothing here"));
    }
    out
}

/// The first unfinished quest's upper-cased title and first open objective.
pub fn quest_lines(character: &Character, content: &Content) -> (String, Vec<Line<'static>>) {
    for q in &character.quests {
        if q.is_done() {
            continue;
        }
        let Some(quest) = content.quest(&q.quest) else { continue };
        let Some(i) = q.done.iter().position(|d| !*d) else { continue };
        let objective = quest.objectives.get(i).cloned().unwrap_or_default();
        return (quest.title.to_uppercase(), vec![plain(objective)]);
    }
    ("QUEST".to_string(), vec![dim("no active quest")])
}

/// Word-wraps `text` to `width` cells; words longer than a row are broken.
fn wrap_text(text: &str, width: usize) -> Vec<String> {
    let width = width.max(1);
    let mut rows = Vec::new();
    let mut row = String::new();
    let mut row_w = 0usize;
    for word in text.split(' ') {
        let mut word: Vec<char> = word.chars().collect();
        while !word.is_empty() {
            let sep = if row_w == 0 { 0 } else { 1 };
            if row_w + sep + word.len() <= width {
                if sep == 1 {
                    row.push(' ');
                }
                row.extend(word.iter());
                row_w += sep + word.len();
                word.clear();
            } else if row_w == 0 {
                let take = width.min(word.len());
                row.extend(word.iter().take(take));
                rows.push(std::mem::take(&mut row));
                row_w = 0;
                word.drain(..take);
            } else {
                rows.push(std::mem::take(&mut row));
                row_w = 0;
            }
        }
    }
    if !row.is_empty() || rows.is_empty() {
        rows.push(row);
    }
    rows
}

fn entry_lines(e: &Entry, width: u16) -> Vec<Line<'static>> {
    let style = match e.kind {
        Kind::Info => Style::default().fg(TEXT),
        Kind::Warn => Style::default().fg(MAGENTA),
        Kind::Story => Style::default().fg(CYAN),
    };
    wrap_text(&e.marked(), width as usize)
        .into_iter()
        .map(|s| Line::from(Span::styled(s, style)))
        .collect()
}

/// Rows `lines` take at `width` when wrapped; at least one per line.
fn rows_for(lines: &[Line<'static>], width: u16) -> u16 {
    lines
        .iter()
        .map(|l| wrap_text(&l.to_string(), width as usize).len() as u16)
        .sum()
}

/// Whole entries from the newest that fit `area`, oldest at the top; the newest reveals.
fn draw_log(log: &MessageLog, tick: u64, area: Rect, buf: &mut Buffer) {
    if area.height == 0 || area.width == 0 {
        return;
    }
    let mut chunks: Vec<Vec<Line<'static>>> = Vec::new();
    let mut rows = 0u16;
    for e in log.iter().rev() {
        let lines = entry_lines(e, area.width);
        if rows + lines.len() as u16 > area.height {
            break;
        }
        rows += lines.len() as u16;
        chunks.push(lines);
    }
    chunks.reverse();
    let n = chunks.len();
    let mut out: Vec<Line<'static>> = Vec::new();
    for (i, lines) in chunks.into_iter().enumerate() {
        if i + 1 == n && let Some(e) = log.latest() {
            let p = tick.saturating_sub(e.tick) as f32 / REVEAL_TICKS as f32;
            out.extend(reveal(&lines, p, (tick / 4).is_multiple_of(2)));
        } else {
            out.extend(lines);
        }
    }
    Paragraph::new(out).render(area, buf);
}

fn list_line(flags: &Sidebar, dev_row: bool) -> Line<'static> {
    let mut spans = vec![Span::raw(" ")];
    for s in Section::ALL.iter().filter(|s| s.dev_only() == dev_row) {
        let on = flags.is_on(*s);
        spans.push(Span::styled(if on { "▣ " } else { "▢ " }, Style::default().fg(if on { CYAN } else { DIM })));
        spans.push(Span::styled(format!("{}  ", s.label()), Style::default().fg(if on { TEXT } else { DIM })));
    }
    Line::from(spans)
}

/// Draws the panel: the section list, then each active section within its budget.
pub fn draw(v: &SidebarView, flags: &Sidebar, area: Rect, buf: &mut Buffer) {
    let title = v.character.handle.to_uppercase();
    let block = boxed(&title);
    let inner = block.inner(area);
    block.render(area, buf);
    if inner.width == 0 || inner.height == 0 {
        return;
    }
    let w = inner.width;
    let mut list = vec![list_line(flags, false)];
    if v.dev {
        list.push(list_line(flags, true));
    }
    let list_h = (list.len() as u16).min(inner.height);
    Paragraph::new(list).render(Rect::new(inner.x, inner.y, w, list_h), buf);
    let body = Rect::new(inner.x, inner.y + list_h, w, inner.height - list_h);
    let node = Digital::node_under(v.city, v.stratum, v.focus).map(|id| v.city.net.node(id));
    let mut built: Vec<(Section, String, Vec<Line<'static>>, u16)> = Vec::new();
    for s in flags.active(v.dev) {
        let (title, lines, need) = match s {
            Section::Here => {
                let l = here_lines(v);
                let n = rows_for(&l, w).min(HERE_CAP - 1) + 1;
                ("HERE".to_string(), l, n)
            }
            Section::Quest => {
                let (t, l) = quest_lines(v.character, v.content);
                let n = rows_for(&l, w).min(QUEST_CAP - 1) + 1;
                (t, l, n)
            }
            Section::Map => (format!("MAP · {}", v.stratum.label().to_lowercase()), Vec::new(), MINIMAP_H + 1),
            Section::Log => ("LOG".to_string(), Vec::new(), 0),
            Section::Inspect => {
                let l = inspector_lines(v.city, v.stratum, v.focus, node, v.ground.at(v.stratum, v.focus), v.content);
                let n = rows_for(&l, w).min(INSPECT_CAP - 1) + 1;
                ("INSPECT".to_string(), l, n)
            }
            Section::Legend => {
                let l = legend(v.stratum);
                let n = l.len() as u16 + 1;
                ("LEGEND".to_string(), l, n)
            }
        };
        built.push((s, title, lines, need));
    }
    let needs: Vec<(Section, u16)> = built.iter().map(|(s, _, _, n)| (*s, *n)).collect();
    let mut y = body.y;
    for (s, rows) in budget(&needs, body.height) {
        let (_, title, lines, _) = built.iter().find(|(x, ..)| *x == s).expect("budgeted");
        Paragraph::new(rule(title, w)).render(Rect::new(body.x, y, w, 1), buf);
        let content = Rect::new(body.x, y + 1, w, rows - 1);
        match s {
            Section::Map => Minimap { city: v.city, stratum: v.stratum, view: v.view, player: v.player, style: v.style }.render(content, buf),
            Section::Log => draw_log(v.log, v.tick, content, buf),
            _ => Paragraph::new(lines.clone()).wrap(Wrap { trim: false }).render(content, buf),
        }
        y += rows;
    }
}
```

```rust
impl Messages {
    pub fn new(_tick: u64) -> Self {
        Messages { scroll: usize::MAX, extent: Cell::new((1, 0)) }
    }

    fn rect(area: Rect) -> Rect {
        let w = (area.width * 7 / 10).max(40).min(area.width);
        let h = (area.height * 7 / 10).max(10).min(area.height);
        Rect::new(area.x + (area.width - w) / 2, area.y + (area.height - h) / 2, w, h)
    }

    fn lines(st: &AppState, width: usize) -> Vec<Line<'static>> {
        let mut out = Vec::new();
        for e in st.log.iter() {
            let style = match e.kind {
                Kind::Info => Style::default().fg(TEXT),
                Kind::Warn => Style::default().fg(MAGENTA),
                Kind::Story => Style::default().fg(CYAN),
            };
            for row in crate::ui::sidebar::wrap_text(&e.marked(), width) {
                out.push(Line::from(Span::styled(row, style)));
            }
        }
        if out.is_empty() {
            out.push(Line::from(Span::styled("nothing yet", Style::default().fg(DIM))));
        }
        out
    }

    fn scroll_by(&mut self, delta: i64) {
        let (rows, total) = self.extent.get();
        let max = total.saturating_sub(rows);
        let cur = self.scroll.min(max) as i64;
        self.scroll = (cur + delta).clamp(0, max as i64) as usize;
    }
}

impl Screen for Messages {
    fn update(&mut self, _st: &mut AppState, keys: &[KeyEvent]) -> ScreenCmd {
        for k in keys {
            let rows = self.extent.get().0 as i64;
            match k.code {
                KeyCode::Down | KeyCode::Char('j') => self.scroll_by(1),
                KeyCode::Up | KeyCode::Char('k') => self.scroll_by(-1),
                KeyCode::PageDown => self.scroll_by(rows),
                KeyCode::PageUp => self.scroll_by(-rows),
                KeyCode::Esc | KeyCode::Char('q') | KeyCode::Char('m') => {
                    return ScreenCmd::Pop { fx: TransitionKind::None };
                }
                _ => {}
            }
        }
        ScreenCmd::Stay
    }

    fn draw(&self, st: &AppState, f: &mut Frame) {
        let r = Self::rect(f.area());
        if r.width < 6 || r.height < 4 {
            return;
        }
        let buf = f.buffer_mut();
        glass(buf, r);
        frame(buf, r);
        put(buf, r.x + 2, r.y, " MESSAGES ", Style::default().fg(CYAN).add_modifier(Modifier::BOLD), r.right() - 1);
        let count = format!(" {} entries ", st.log.len());
        put(buf, r.right().saturating_sub(count.chars().count() as u16 + 2), r.y, &count, Style::default().fg(DIM), r.right() - 1);
        let inner = Rect::new(r.x + 2, r.y + 2, r.width - 4, r.height - 4);
        let lines = Self::lines(st, inner.width as usize);
        let rows = inner.height as usize;
        self.extent.set((rows.max(1), lines.len()));
        let max = lines.len().saturating_sub(rows);
        let start = self.scroll.min(max);
        let shown: Vec<Line<'static>> = lines.into_iter().skip(start).take(rows).collect();
        put_paragraph(buf, inner, shown);
    }
}
```
